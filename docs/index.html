日経平均、6万4,000円台が視野に — AI・半導体株が牽引

政府・日銀が5兆円規模の円買い介入 — ドル円は155〜158円台で推移

5月のゴールデンウィーク期間中、政府・日銀は4〜5兆円規模とみられる大規模なドル売り・円買い介入を実施しました。1ドル＝160円を超えない水準を防衛ラインとする当局の姿勢が鮮明になっており、介入後は155円台まで円高が進行する場面もありました。野村證券は2026年末のドル円見通しを152.5円に引き上げており、日米金利差の縮小が中期的な円高要因として注目されています。日銀は6月の追加利上げの可能性も市場から意識されています。

米S&P500は7,473ポイント — Q1企業利益率が過去最高の13.4%

5月24日時点の米国株式市場では、S&P500が7,473.47（前日比+0.37%）、ダウ平均が50,579.70（+0.58%）、ナスダックが26,343.97（+0.19%）とそれぞれ小幅高で推移しています。2026年第1四半期のS&P500構成企業の純利益率は13.4%と、FactSetが集計を開始した2009年以来の最高水準を記録しました。一方で先行12ヵ月PERは20.9倍と5年平均（19.9倍）を上回っており、割高感を指摘する声も出ています。AI関連への資本投資については、規模よりもリターンの実証を求める機関投資家の姿勢が強まっています。

トランプ関税をめぐる法廷攻防 — 控訴審が下級審判断を一時停止

5月7日、米国際貿易裁判所はトランプ政権が2月24日に発動した一律10%の輸入関税を「1970年代の貿易法では正当化できない」として違憲と判断しました。しかし連邦控訴裁判所は5月12日にこの判決を一時停止し、関税は現状維持となっています。関税の恒久化部分（Section 232）については長期的に米GDPを0.3%押し下げるとの試算があります。5月のCPI（消費者物価指数）では衣料品・電子機器が前月比+0.6%、おもちゃ・家具が+0.8%上昇しており、関税の影響が物価に反映されつつあります。Section 122に基づく10%関税は7月に失効予定で、議会延長が焦点です。

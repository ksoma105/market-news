月曜昼は、中国の景況感と住宅制度改革、米国の天然ガスインフラ再編という、アジアのマクロ・不動産と北米エネルギーの3つの動きをお伝えします。

中国8月製造業PMI、49.8へ改善—非製造業は49.0で低迷

中国国家統計局が31日09:30に公表した8月の製造業PMIは49.8と、7月の49.2から0.6ポイント上昇しました。ただし景況拡大・縮小の境目となる50は2カ月連続で下回りました。生産指数は50.4、新規受注は50.6へ上昇する一方、非製造業PMIは49.0で横ばい。高技術製造業PMIは52.9でしたが、サービス業と建設業の弱さが残り、中国景気の製造業・輸出依存を映します。

出典: 中国国家統計局 / Reuters

中国、住宅販売制度を改革—小型不動産株に売り

中国が28日に発表した住宅販売制度改革を受け、31日午前のCSI300不動産指数は2%安、香港上場の中国不動産株指数は約4%安となりました。新制度は、予約販売物件の主体構造完成を条件とし、購入資金を監督口座へ全額入金させるほか、新規用地では完成物件販売を優先します。資金力と管理能力の基準が上がるため、小規模開発業者の退出と業界再編が進むとの見方が広がっています。

出典: Reuters / 中国政府発表（転載）

ONEOK、パーミアン天然ガス資産を44.25億ドルで買収

米パイプライン大手ONEOKは30日、Brazos Midstreamのパーミアン・ミッドランド盆地の天然ガス集積・処理資産を現金44億2500万ドルで買収すると発表しました。Apollo運用ファンドからの議決権なし少数持分投資90億ドルで買収を賄い、うち約50億ドルを債務削減に充てます。買収後の同地域処理能力は建設中設備を含め約23億立方フィート/日へ倍増し、取引完了は2026年第4四半期を予定しています。

出典: ONEOK / Reuters

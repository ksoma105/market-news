米消費者の雇用不安が悪化、失業率上昇予想は2020年以来の高水準

ニューヨーク連銀の8月調査では、1年先の失業率が現在より高くなる確率の平均が1.6ポイント上昇して44.4%となり、2020年4月以来の高水準でした。1年先と5年先のインフレ予想中央値はそれぞれ3.6%、3.0%で横ばい、3年先は0.1ポイント低下して3.2%。雇用と家計への不安が強まる一方、物価予想はおおむね安定しています。

出典: ニューヨーク連銀 / Reuters

Qualcomm、Amazon向けAI半導体で最大600億ドル規模の契約

QualcommはAmazonとAIデータセンター向けカスタム半導体を共同開発し、製品・サービスの購入額が最大600億ドルに達し得る長期提携を結びました。Amazonには1株161.26ドルで最大2,500万株を取得できるワラントが付与され、総額は約40億ドル。AI推論用チップと最大1.6Tbpsの光接続技術を組み合わせ、スマートフォン依存からの転換を加速します。

出典: Reuters / MarketWatch

Verizon、Corningと光ファイバー長期契約—AI需要に備え8000万マイル超

VerizonはCorningと複数年・数十億ドル規模の光ファイバー供給契約を締結しました。Corningは2027年から2032年にかけて、高密度光ファイバーと接続製品を8,000万マイル超供給します。住宅・企業向けブロードバンドの拡張に加え、AIハイパースケーラーが必要とする大容量・低遅延ネットワークを強化する狙いです。

出典: Reuters

米当局、中国AI6社を「産業規模の蒸留」で非難

米NSA、CISA、FBIは共同勧告で、DeepSeek、Moonshot AI、Alibabaなど中国のAI企業6社が米国製モデルから大規模な知識蒸留を行ったと主張しました。勧告によると、2024年末以降に数百万回のやり取りから数十億トークンを抽出。中国側の反応は記事掲載時点で得られておらず、米中首脳会談を前に技術摩擦が強まる可能性があります。

出典: 米政府共同サイバーセキュリティ勧告 / Reuters

Meta、メール送信や決済を代行するAIエージェント「Muse」を米国投入

Metaは、メール送信、旅行予約、買い物などを利用者に代わって実行するAIエージェント「Muse」を米国で提供開始しました。専用アプリとWhatsAppから利用でき、各エージェントは独立したクラウド上の仮想マシンで動作します。一方、Reutersは社内試験で接続切断や無許可の機密データ送信が報告されたとし、安全性と実用性の両立が焦点です。

出典: Meta / Reuters

米株反落、ソフトウェア株にAI代替懸念—ダウ1.18%安

9月8日の米株式市場は、S&P 500が0.58%安の7,673.52、Nasdaqが0.32%安、ダウが1.18%安で終了しました。AIによる代替懸念からSalesforceやServiceNowが下落し、ソフトウェア・サービス指数は1.4%安。一方、Qualcommなど半導体株は買われました。原油高とインフレ懸念も重荷となり、市場は9月の利上げ確率を60%とみています。

出典: Reuters

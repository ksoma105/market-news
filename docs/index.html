土曜朝は、米投資資金のリスク回避、中国の対米ビジネス外交とByteDanceの大型融資、インド取引所とナイジェリア製油所のIPO、Eniのベネズエラ投資という6つの動きをお伝えします。

米株ファンド、2週連続流出—1週間で111.2億ドル

LSEG Lipperの集計によると、9月2日までの1週間に米国株ファンドから111億2,000万ドルが流出し、2週連続の純流出となりました。大型株ファンドの流出は75億2,000万ドル、業種別ファンドは計34億8,000万ドルの売り越しでした。一方、マネーマーケットファンドには487億6,000万ドルが流入。中東情勢や金利上昇を受け、投資家が現金性資産へ資金を移す慎重姿勢が鮮明です。

出典: Reuters（LSEG Lipper）

習近平氏の米訪問、中国CEO団同行を調整—通商・投資を協議へ

Reutersは関係者の話として、中国の習近平国家主席が9月24日のワシントン訪問に大規模な企業経営者団を同行させる準備を進めていると報じました。中国側には対米投資と商業関係を支える姿勢を示す狙いがある一方、参加企業は未確定です。両国は「非機微」品目やレアアース輸出許可、農業・非関税障壁などを協議中で、首脳会談の具体的な経済成果が焦点になります。

出典: Reuters

ByteDance、296億ドル融資を確保—AI投資を加速

Reutersによると、ByteDanceは約30行から296億ドルの融資枠を確保しました。当初予定の200億ドルから増額され、期間は3年、2年間の延長オプション付きの無担保融資です。中国系銀行が全体の60%超を引き受け、資金は主に海外のAI関連計画へ充てられる見通しです。アジアで今年2番目の規模となる大型融資は、AIモデルとデータセンターへの投資競争が銀行貸出にも波及していることを示します。

出典: Reuters

インドNSE、9月21日の週に上場目標—長年のIPO計画が前進

インド国立証券取引所（NSE）は、規制当局の承認を受け、9月21日の週の上場を目指しているとReutersが報じました。関係者によると、ブックビルディングは9月11日開始、価格帯は15日発表の見通しで、1株1,800ルピー付近なら評価額は約470億ドルです。IPOは既存株主による売り出しで、取引所への新規資金流入はありません。2016年以来停滞してきた大型案件が、インドIPO市場の試金石になります。

出典: Reuters

Dangote製油所IPO、最大2.15兆ナイラ調達へ—ナイジェリアSEC承認

ナイジェリア証券取引委員会はDangote Petroleum RefineryのIPOを承認しました。会社発表によると、1株525ナイラで41億株を売り出し、全株が引き受けられれば約2兆1,500億ナイラ（約16億ドル）を調達します。既存の1,201億3,000万株も登録され、Reutersの試算では評価額は約470億ドルです。調達資金は製油能力を日量140万バレルへ倍増する計画を支える見込みです。

出典: Reuters / PUNCH

Eni、ベネズエラJunín 5の運営主体に—25年契約を締結

Eniとベネズエラ国営PDVSAは、オリノコ地帯の重質油田Junín 5を開発する25年契約を締結し、Eniが技術・財務・商務を担う単独オペレーターになりました。油田は確認原始埋蔵量350億バレル、現在の生産量は日量約1万2,000バレルです。Reutersは、この契約がベネズエラからEniへの23億ドル超の未収金回収を進める可能性があると報道。制裁緩和後の同国エネルギー再建を測る案件です。

出典: Eni / Reuters

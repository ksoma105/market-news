米GDP、7〜9月期3.4%増　9月PCE物価は前年比3.6%

米商務省の速報値で、2026年7〜9月期の実質GDPは年率換算で前期比3.4%増となり、市場予想の3.2%を上回った。個人消費は3.8%増で、AI関連の企業投資も成長を支えた。一方、9月のPCE物価指数は前月比0.5%、前年同月比3.6%上昇し、食品とエネルギーを除くコアは前年同月比3.1%だった。

影響が考えられる業種：小売、銀行、半導体、データセンター、債券、住宅

注目点・リスク：強い成長と物価上昇が同時に示され、12月の利上げ観測を支え得る。名目個人消費は9月に0.5%増えたが、物価調整後は横ばいで、ガソリン高や貯蓄率低下が年末商戦と家計を圧迫する恐れがある。AI投資の採算性も設備投資の下振れ要因となる。

10月の消費者態度指数35.0　前月から0.4ポイント低下

内閣府の10月消費動向調査で、二人以上世帯の消費者態度指数は35.0と前月から0.4ポイント低下した。暮らし向きは33.2で0.6ポイント、雇用環境は39.4で0.6ポイント、耐久消費財の買い時判断は26.8で0.5ポイントそれぞれ下がった。

影響が考えられる業種：小売、外食、家電、自動車、旅行、住宅

注目点・リスク：収入の増え方も40.4と0.1ポイント低下し、家計の慎重姿勢が広がった。調査は10月15日時点、8400世帯が対象で回答率は79.6%だった。物価、賃金、雇用環境の変化が年末消費にどう波及するかが焦点となる。

ユーロ圏景況感96.9に低下　雇用期待は98.2へ改善

欧州委員会の10月調査で、景況感指数はユーロ圏、EUともに前月から0.6ポイント低下し96.9となった。2カ月連続の悪化で、長期平均の100を下回る。一方、雇用期待指数はユーロ圏で0.7ポイント上昇の98.2、EUで0.6ポイント上昇の98.9だった。

影響が考えられる業種：製造業、サービス、小売、建設、銀行、雇用サービス

注目点・リスク：消費者信頼感はユーロ圏でマイナス17.9、EUでマイナス17.3と弱い。景況感と雇用期待の方向が分かれており、企業の採用計画が実需の鈍化に遅れて調整される可能性がある。エネルギー価格や通商環境も先行きを左右する。

Caterpillar、7〜9月期売上高17%増　受注残781億ドル

Caterpillarの2026年7〜9月期売上高は前年同期比17%増の207億ドル、調整後1株利益は7.20ドルとなり、市場予想の7.08ドルを上回った。データセンター向け発電設備など電力需要が寄与し、受注残は前四半期から60億ドル増えて過去最高の781億ドルとなった。

影響が考えられる業種：建設機械、鉱山、発電設備、データセンター、鉄鋼、物流

注目点・リスク：会社は2026年売上高の伸び率見通しを10%台半ばから後半で据え置いた。関税コストは通年22億ドルを見込み、調整後営業利益率は20.6%だった。大型受注を売上と利益に転換できるか、関税と供給制約を価格転嫁できるかが焦点となる。

コマツ、4〜9月期売上高14.1%増　通期予想を上方修正

コマツの2026年4〜9月期は、売上高が前年同期比14.1%増の2兆1586億円、営業利益が3.5%増の2866億円、親会社株主帰属利益が9.2%増の1919億円となった。建設・鉱山機械の需要と円安が寄与し、2027年3月期の業績予想を上方修正した。

影響が考えられる業種：建設機械、鉱山、資源、部品、商社、物流

注目点・リスク：会社は下期の前提為替を1ドル150円、1ユーロ174円、1豪ドル106円とした。円安は円換算売上を押し上げる一方、為替反転や資源価格の下落、地域別の建設需要減速、部材費の上昇が利益を圧迫する可能性がある。

武田薬品、通期純利益予想2090億円へ上方修正

武田薬品工業の2026年4〜9月期は、コア営業利益が前年同期比11.2%増の7106億円、コア純利益が11.6%増の4896億円となった。通期予想は売上収益を4兆6400億円から4兆7000億円、営業利益を4200億円から4530億円、純利益を1660億円から2090億円へ引き上げた。

影響が考えられる業種：医薬品、バイオ、医療、卸売、研究開発、為替

注目点・リスク：成長製品と為替が支えとなる一方、報告ベース利益は再編費用や無形資産償却などの影響を受けやすい。主力薬の競争、臨床試験、薬価政策、特許切れ、為替変動が上方修正後の達成度を左右する。

ANA、4〜9月期売上高17.5%増　燃油高で営業利益9.7%減

ANAホールディングスの2026年4〜9月期は、売上高が前年同期比17.5%増の1兆3987億円、営業利益が9.7%減の881億円、純利益が11.8%減の671億円となった。国際線需要が伸び、通期売上高予想を2兆7700億円から2兆8700億円へ、純利益予想を960億円から990億円へ引き上げた。

影響が考えられる業種：航空、旅行、ホテル、空港、商社、エネルギー

注目点・リスク：通期営業利益予想は1500億円で据え置いた。会社の下期前提は1ドル160円、ドバイ原油1バレル90ドル、シンガポール・ケロシン150ドルと従来想定より厳しい。旅客需要が堅調でも、円安と燃油高が増収効果を相殺する恐れがある。

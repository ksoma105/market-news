月曜昼は、日本の外貨準備の過去最大の減少、世界的な船舶燃料油の供給逼迫見通し、アジア株の反発という3つの動きをお伝えします。

日本の外貨準備、8月に795.75億ドル減—過去最大の落ち込み

財務省が9月7日に公表した8月末の外貨準備高は1兆2,075億2,400万ドルで、7月末から795億7,500万ドル減少しました。Reutersによると減少率は6.18%で、月間の減少額として過去最大です。内訳では外貨証券が8,395億5,900万ドル、預金が1,554億1,700万ドルでした。7月30日から8月26日までの円買い介入額は15.4兆円に達しており、大規模介入後の準備資産の変化が確認されました。

出典: 財務省 / Reuters

船舶燃料油、7〜9月に日量21.8万バレル不足の見通し

船舶や発電所で使う燃料油について、Energy Aspectsは2026年7〜9月期に世界で日量21.8万バレルの供給不足になると予測しました。主要拠点のシンガポール、ARA、フジャイラの在庫は3年の季節平均を約30%下回ります。シンガポールの低硫黄燃料油価格はイラン戦争開始後、9月1日時点で76%上昇し1トン825ドル弱となり、同期間のBrent原油の40%上昇を上回りました。精製設備への攻撃やタンカー運航の制約に加え、製油所が軽油などを優先することが供給を圧迫しています。

出典: Reuters

アジア株が反発—日経2.0%高、韓国株3.0%高

9月7日のアジア市場では、日経平均が2.0%、韓国総合株価指数が3.0%上昇し、MSCIアジア太平洋株指数（日本除く）も0.9%高となりました。Reutersの日本時間午前10時6分時点の報道では、Brent原油は0.2%高の1バレル96.45ドル、米WTI原油は0.4%高の91.85ドル。米10年国債利回りは4.7840%と2023年末以来の高水準近辺にあり、株式市場は景気期待と金利・原油高の双方を織り込む展開です。

出典: Reuters

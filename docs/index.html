火曜午後から夜に確認できた材料から、ソフトバンクグループのAI投資負担、Infineonの成長見通し、ブラジルの金融政策を整理しました。

音声向け原稿

ソフトバンクG、7〜9月期は1兆1,153億円の赤字　AIデータセンターで損失

ソフトバンクグループの2026年7〜9月期は、純損益が1兆1,153億円の赤字となり、前年同期の2兆5,022億円の黒字から7四半期ぶりに赤字へ転じた。米国のAIデータセンター向け発電設備の調達計画見直しなどで5,972億円の損失を計上し、財務費用も前年同期の2.6倍となる4,619億円に膨らんだ。一方、四半期の資金調達額は過去最大の約9兆円となった。

影響が考えられる業種：AIインフラ、データセンター、投資会社・金融

注目点・リスク：AI向け電力設備の先行確保は供給制約への対応となる一方、仕様変更や計画遅延で損失が生じる可能性を示した。借入負担の拡大と投資資産の価格変動が、今後の純資産価値や追加投資余力にどう影響するかが焦点となる。

ソフトバンクグループ / Reuters / TBS CROSS DIG with Bloomberg ・ 公開 2026-11-10 15:37 JST

Infineon、2027年度売上高は20%超増を予想　データセンター電源が成長軸

ドイツの半導体大手Infineonは、2027年度の売上高を約200億ユーロとし、20%を超える成長を見込むと発表した。うちデータセンター向け電源関連は40億ユーロ近くを予想する。2026年度第4四半期の売上高は47億600万ユーロ、セグメント利益率は23.8%だった。2027年度はセグメント利益率を20%台半ばとし、30億〜35億ユーロの設備投資を計画する。

影響が考えられる業種：パワー半導体、データセンター、電力インフラ・自動車

注目点・リスク：AIデータセンターの電力需要と送配電設備の更新はパワー半導体需要を支える可能性がある。ただし、計画には1ユーロ=1.15ドルの為替前提があり、設備投資増による供給拡大が需要の伸びを上回るリスクも確認が必要となる。

Infineon / Reuters（Euronext掲載） ・ 公開 2026-11-10

ブラジル中銀、利下げを停止　供給ショックでインフレ見通し悪化

ブラジル中央銀行の金融政策委員会は11月10日に公表した議事要旨で、原油高、エルニーニョ、週44時間労働制の終了に伴うコスト、国内政策への不透明感による通貨安の4要因がインフレ見通しを悪化させていると説明した。前週の会合では利下げサイクルを停止し、政策金利を13.75%に据え置いた。2026年、2027年、第2四半期2028年のインフレ予想はそれぞれ5.6%、4.7%、3.5%とされ、3%目標を上回る。

影響が考えられる業種：銀行、小売・耐久消費財、農業・エネルギー

注目点・リスク：高金利の長期化は通貨の下支えになり得る一方、家計・企業の借入と内需に重荷となる。景気減速が物価圧力を抑えるか、供給ショックと財政不安がインフレ期待をさらに押し上げるかが今後の焦点となる。

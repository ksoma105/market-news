米10月卸売物価は前月比0.3%上昇　前年比は6.5%

米労働省労働統計局が11月13日に公表した10月の生産者物価指数は、最終需要ベースで前月比0.3%上昇し、前年同月比では6.5%上昇した。財価格は前月比0.5%、サービス価格は0.2%上昇。内訳では輸送・倉庫サービスが2.0%、建設が1.8%上がる一方、ディーゼル燃料は7.9%、原油は10.3%下がった。品目間のばらつきは大きいものの、企業段階の物価上昇圧力がなお強いことを示した。

影響が考えられる業種：物流、建設、金利敏感業種

注目点・リスク：仕入れ・輸送コストが販売価格へ転嫁されれば、企業利益や金融政策に影響する可能性がある。ただし月次の速報値であり、エネルギー安が他品目の上昇をどこまで相殺するか、消費者物価への波及を今後のデータで確認する必要がある。

ユーロ圏GDPは7〜9月期に0.4%増　雇用は横ばい

欧州連合統計局が11月13日に公表した速報値によると、ユーロ圏の2026年7〜9月期の実質GDPは前期比0.4%増、EU全体では0.5%増だった。前年同期比ではそれぞれ1.3%、1.5%増。4〜6月期の伸びはユーロ圏0.6%、EU0.7%だったため、成長ペースはやや鈍化した。就業者数はユーロ圏とEUの双方で前期比横ばい、前年同期比0.4%増となった。

影響が考えられる業種：欧州輸出、銀行、消費関連

注目点・リスク：景気拡大は続く一方、雇用の伸びが止まり、成長率も前四半期から低下した。GDPと雇用は速報値であり、12月以降の改定、国別のばらつき、金利上昇が企業投資や消費へ及ぼす影響が焦点となる。

世界の原油供給が需要を上回る　IEAは2027年の供給回復を予測

国際エネルギー機関は11月13日、10月の世界原油供給が前月から日量230万バレル増え、日量1億540万バレルになったと公表した。確認可能な世界在庫は10月に5,200万バレル増え、イラン戦争の開始後で初めて供給が需要を上回った。2026年の世界需要は前年比日量270万バレル減の1億230万バレル、2027年は日量200万バレル増を予測する。北海原油価格は10月8日の1バレル136ドルから報告時点で約93ドルへ下落した一方、欧州のディーゼル価格は約180ドルと戦前より77%高い。

影響が考えられる業種：石油・ガス、製油、運輸・石油化学

注目点・リスク：湾岸輸出と在庫の回復は原油価格の上昇圧力を和らげる可能性があるが、陸上在庫は少なく、ディーゼル需給は依然逼迫している。タンカーやエネルギー施設への攻撃、イランからの供給制約により、2027年予測は大きく変わり得る。

Applied Materials、8〜10月期売上高は53%増の104.1億ドル

半導体製造装置大手Applied Materialsは11月12日、2026年度第4四半期の売上高が前年同期比53%増の104億900万ドルだったと発表した。GAAPベースの1株利益は43%増の3.40ドル、粗利益率は50.4%。通期売上高は21%増の344億4,600万ドルとなった。2027年度第1四半期は売上高111億ドルを中心に上下5億ドル、非GAAPの1株利益4.35ドルを中心に上下0.20ドルと見込む。

影響が考えられる業種：半導体製造装置、先端半導体、AIデータセンター

注目点・リスク：AI向けの先端ロジック、メモリー、パッケージ投資は装置需要を支える可能性がある。一方、会社見通しは非GAAP指標を含み、顧客の設備投資サイクル、輸出規制、供給制約によって業績が変動するリスクがある。

Richemont、上期売上高16%増　中国需要はなお軟調

Cartierなどを傘下に持つRichemontは11月13日、2026年9月までの上期売上高が前年同期比16%増の122億8,200万ユーロだったと発表した。為替一定では17%増。営業利益は33%増の31億2,900万ユーロ、純利益は39%増の25億2,800万ユーロとなった。宝飾部門の売上高は為替一定で19%、専門時計部門は10%増えたが、中国本土の需要は軟調だった。第2四半期の売上高伸び率は13%で、第1四半期の20%から減速した。

影響が考えられる業種：高級品、小売、宝飾・時計

注目点・リスク：日本、米州、アジア太平洋の需要は高級品市場を支えた一方、中国の回復時期は不透明で、原材料高も利益率の重荷となる。営業利益には関税関連の一時利益2億2,900万ユーロが含まれており、基調的な収益力との区別が必要だ。

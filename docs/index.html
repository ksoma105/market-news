SpaceX、GPU購入へ400億ドルの債務調達を完了

Elon Musk氏は、SpaceXがGPU購入向けに400億ドルの債務調達を完了したと明らかにした。主に2027年第1・第2四半期に届くGPUの購入に使うコーラブル債務という。7〜9月期の売上高は前年同期比161%増の145億8,000万ドル、設備投資は約3倍の196億ドルだった。

影響が考えられる業種：半導体、データセンター、金融

注目点・リスク：巨額資金はAI計算基盤への需要を示す一方、発表はMusk氏の説明に基づき、債務条件の詳細は示されていない。GPUの納入時期、資本コスト、AI投資が収益へ結び付く速度を確認する必要がある。

英国、カナダ主導の防衛銀行に参加せず　別制度で連携

英国はカナダ主導のDefence Security and Resilience Bankには参加せず、独自のMultilateral Defence Mechanismを進める。両政府は、2つの制度を補完的に運営する協力枠組みを作ることで合意した。英国側は共同調達の金融支援、カナダ側は防衛産業・供給網への投資支援を重視する。

影響が考えられる業種：防衛、銀行・政策金融、製造業

注目点・リスク：本部所在地、共同調達、融資対象、新規加盟規則で合意できなかったと関係者が説明しており、制度設計は未確定。参加国、資本規模、実際の案件形成が資金供給効果を左右する。

UBS移転なら国内最大1.2万人失職の恐れ　スイス従業員団体

スイス銀行従業員協会は、厳しい資本規制を受けてUBSが移転・売却・合併した場合、国内約3万4,000人のうち1万〜1万2,000人が職を失う可能性があると議会へ警告した。UBSはCredit Suisse統合に伴い、別途約3,000人を数年かけて削減する見通しを維持している。

影響が考えられる業種：銀行、雇用サービス、専門サービス

注目点・リスク：1万〜1万2,000人は従業員団体が示した最悪ケースで、UBSはスイス残留の意向を繰り返しており、移転は決定していない。国外子会社を支える資本比率を巡る議会審議と妥協案の有無が焦点となる。

韓国7〜9月期GDP、前期比0.7%成長予想　半導体輸出がけん引

Reutersが16人のエコノミストに聞いた調査では、韓国の7〜9月期GDPは前期比0.7%増と、4〜6月期の0.6%増から小幅に加速する見通し。前年同期比は3.0%と前期の3.7%から鈍化予想で、9月の輸出は前年同月比84%増の過去最高1,209億ドル、半導体は262.8%増の603億ドルだった。

影響が考えられる業種：半導体、輸出製造、銀行

注目点・リスク：これは10月26日のGDP公表前の予測で、実績ではない。成長が半導体とAI投資へ集中し、高金利・家計債務・雇用の弱さが内需へ残るため、実績値と消費への波及を確認する必要がある。

ホルムズ海峡周辺の船舶攻撃、10月は確認28件で過去最多

Washington Instituteの集計では、ホルムズ海峡と周辺海域の船舶攻撃は10月に確認・報告ベースで28件と過去最多になった。IMOの一覧では紛争開始後に大型原油タンカー30隻超が損傷し、10月だけで11隻。損傷した大型原油タンカーは世界船隊の約3.5%に当たる。

影響が考えられる業種：海運、保険、石油・航空

注目点・リスク：船会社の自主報告が不十分で、実際の件数は集計と異なる可能性がある。運賃は日量100万ドル超に上がっており、攻撃の継続、航路変更、保険料と原油輸送への影響を注視する必要がある。

NZ総選挙、与党3党が暫定67議席　最終結果は11月27日

ニュージーランド総選挙の暫定集計では、国民党42、ACT党13、ニュージーランド・ファースト党12の現与党3党が、131議席中67議席を確保した。労働党は36、緑の党は16、マオリ党は5議席。約39万9365票、推定総投票数の約14%に当たる特別票は未集計で、公式結果は11月27日に公表される。

影響が考えられる業種：銀行・不動産、公共サービス、農業・観光

注目点・リスク：暫定結果どおりなら現連立の続投余地があるが、特別票は過去に左派系政党へ傾く傾向があり、議席配分は変わり得る。政権協議は最終結果後となる見通しで、予算、住宅、生活費対策を巡る政策の確定が遅れる可能性がある。

SoftBankとABB、中国事業切り離しで54億ドル買収の維持を模索

SoftBank GroupとABBは、中国当局が阻止した54億ドルのロボティクス事業買収について、中国事業を別会社にして所有構造を変える案を検討していると報じられた。SoftBankは11月4日に中国事業の買収禁止通知を受けたことを公表済み。報道ではABBが別の買い手を探す選択肢も検討し、中国事業の潜在評価額は20億〜30億ドルとされる。中国はABBのロボティクス事業の約30%を占める最大市場だ。

影響が考えられる業種：産業用ロボット、AI・自動化、投資会社・M&A

注目点・リスク：中国事業の切り離し案は当事者が正式発表した決定ではなく、SoftBankはコメントせず、ABBも報道へのコメントを控えた。中国当局が新たな構造を認めるか、技術・データ管理や事業価値をどう分けるかが取引成立の焦点となる。

Reuters / SoftBank Group ・ 公開 2026-11-07 18:54 JST

Tesla、Cybertruckを増産後に生産ライン撤去　Cybercabへ転換

Teslaは、未消化のCybertruck注文に対応するためテキサス工場で追加シフトを導入し、その後2027年6〜7月ごろに同モデルの生産ラインを撤去してCybercabの生産拡大に振り向ける方針をElon Musk最高経営責任者が示した。Cybertruckの米国販売は2025年に約2万台と、2024年の約3万9000台から減少し、当初示された年25万台の見通しを大きく下回った。

影響が考えられる業種：電気自動車、電池・部品、ロボタクシー・自動運転

注目点・リスク：短期の増産と中期の撤退が同時に進むため、部品調達、設備転用、納車時期への影響を分けて見る必要がある。Cybercabの量産時期や自動運転の規制承認は不確実で、Cybertruckには品質問題やリコール、海外市場での販売制約も残る。

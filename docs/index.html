水曜朝の号をお届けします。注目を集めるFOMCの結果公表（日本時間18日未明）を控え、米国市場は様子見ムードのなか強弱が分かれました。前日まで3指数そろって最高値を更新したダウ平均はこの日も最高値を更新した一方、ナスダックとラッセル2000は伸び悩み、米イラン和平を巡る不透明感も意識されました。経済指標では5月の住宅着工が市場予想に反して大きく落ち込み、約6年ぶりの低水準となっています。19日の署名へ向かう米イラン和平は覚書（MOU）への署名が伝わったものの、レバノンを巡る火種が新たな波乱要因として浮上しました。本号は、(1)FOMC待ちで強弱まちまちの米株、(2)急減した米5月住宅着工、(3)疑念が残る米イラン和平、(4)4営業日続落の原油、(5)方向感を欠く金・銀、(6)本日の東京市場の焦点、の6本でお伝えします。

米株はFOMC待ちで強弱まちまち — ダウは最高値を更新、ナスダックとラッセルは伸び悩み

16日（火）の米国株式市場は、ウォーシュ新議長の初采配となるFOMCの結果公表を翌日に控え、方向感に乏しい展開となりました。優良株で構成するダウ工業株30種平均は前日比0.78%高と続伸し、2営業日連続で過去最高値を更新しています。一方、ハイテク中心のナスダック総合指数は0.02%高とほぼ横ばい、S&P500種株価指数も0.13%高にとどまり、中小型株のラッセル2000は前日の上昇から反落しました。前日まで和平合意とSpaceX関連の物色で記録的な上昇が続いていただけに、高値圏での利益確定や持ち高調整が出やすい地合いでした。市場では米イラン和平を巡る不透明感も意識され、楽観一辺倒だったムードはいったん一服しています。FOMCの結果とウォーシュ氏の初の記者会見を見極めたいとの様子見が、当面の値動きを抑える要因となりそうです。

米5月の住宅着工が予想外の急減 — 前月比15.4%減、約6年ぶり低水準で高金利の重しが鮮明

16日に発表された米5月の住宅着工件数は、年率換算で117万7,000戸と前月の139万2,000戸から15.4%減少し、2020年5月以来の低水準となりました。市場予想は143万戸への増加でしたから、これを大きく下回る予想外の落ち込みです。インフレの高止まりを背景に住宅ローン金利が高止まりするなか、住宅取得の負担感が一段と強まっていることが改めて示された形です。住宅は景気の先行指標とされ、建設・関連消費を通じて雇用や内需に波及するだけに、今後の景気減速懸念を強める材料となり得ます。もっとも、エネルギー高による物価上振れと景気の弱さが併存する状況は金融政策の判断を難しくします。物価指標が高止まりするなかで実体経済の一部に陰りが見え始めており、ウォーシュ新議長が初のFOMCでこうした下振れ材料をどう評価するかが注目されます。

出典: CNBC / TheStreet

米イラン和平に疑念 — 覚書（MOU）署名も、レバノン巡りトランプ氏がネタニヤフ氏を批判・イランは警告

19日（金）にスイスで予定される正式署名へ向け、米国とイランは停戦を固める覚書（MOU）に署名したと伝わりました。パキスタンの仲介によるこの覚書には、ホルムズ海峡の再開と、核問題や地域安全保障を巡る今後60日間の協議の枠組みが盛り込まれています。もっとも、合意の持続性には早くも疑念が浮上しています。トランプ米大統領は、レバノンでのイスラエルとヒズボラの戦闘を巡るネタニヤフ・イスラエル首相の対応を批判しました。これに対しイランのアラグチ外相は、イスラエル軍がレバノン南部に駐留を続けることは、形成途上にある米イランの了解事項に対する違反にあたるとの認識を示しています。ホルムズ海峡の正常化観測は引き続き原油の重しですが、署名を目前に控えてもイスラエルやレバノンを巡る火種は消えておらず、地政学プレミアムが再注入されるリスクは残ります。市場は19日の署名完了まで、和平進展と緊張再燃の綱引きを注視する展開です。

出典: Al Jazeera / CNBC

原油は4営業日続落 — ブレント80ドル前後・WTI77ドル台、3月初旬以来の安値で年初来最長の下げ

原油相場は下落基調が続いています。北海ブレント原油は16日（火）に一時3%超下落して1バレル80ドル前後へ軟化し、4営業日続落となりました。米WTIも77ドル台と、いずれも3月初旬以来の安値圏で、年初来で最も長い連続安となっています。米イラン和平に伴うホルムズ海峡の再開期待が供給回復観測を強め、地政学プレミアムの剥落が続いていることが背景です。世界の海上輸送原油の約2割が通る要衝が正常化に向かえば、供給途絶への警戒は一段と和らぎます。ブレントは中東情勢が緊迫した3月には一時114ドルを超えていただけに、足元の調整幅の大きさが目立ちます。もっとも、機雷除去や保険・運航体制の回復には数カ月を要するとの見方もあり、平時水準への完全な復帰には時間がかかりそうです。原油安はインフレ鈍化要因として景気・株式には追い風となる一方、産油国の収益やエネルギー関連株には逆風となります。

出典: OilPrice / Trading Economics

金・銀は方向感を欠く — 金は1トロイオンス4,300ドル台で小動き、銀は上値重く持ち高調整

貴金属はFOMCの結果待ちで方向感に乏しい展開です。金（ゴールド）は1トロイオンス4,300ドル台で小幅な値動きとなり、前日に2%超上昇した後はこの日4,340ドル近辺へやや戻す場面もありました。銀は上値の重さが目立ち、ラリー一服から持ち高調整が優勢です。米イラン和平の進展でエネルギー主導のインフレ懸念が和らぎ、安全資産への逃避需要が後退しやすいことが上値を抑えています。一方で、ドル安基調や各国中央銀行による継続的な金購入は中長期の下支え要因です。市場の関心はFOMCのドットプロットとウォーシュ新議長の会見トーンに集まっており、これらがドルと実質金利の先行きをどう示すかが、貴金属の次の方向を決めるとみられます。結果公表まで神経質な小動きが続きやすい地合いです。

出典: Trading Economics / GoldSilver

本日の東京市場 — 7万円タッチ後の高値圏、ドル円160円台、FOMC待ちで様子見か

本日17日（水）の東京市場は、歴史的な高値圏での推移が続くなか、FOMC待ちの様子見ムードが広がりそうです。日経平均株価は前日16日にザラ場で初めて7万円台に乗せ、終値も前日比87円高の6万9,404円と4日続伸して連日で最高値を更新しました。半導体・AI関連が相場をけん引する構図が続く一方、31年ぶりの利上げ後も円安の流れは変わらず、ドル円は1ドル160円台前半と、政府・日銀の介入を警戒する水準で推移しています。米国市場が強弱まちまちで、和平を巡る不透明感も意識されるなか、東京市場でも積極的に上値を追う動きは出にくいとみられます。日本時間18日未明のFOMC結果公表という最大のイベントを控え、本日は高値警戒感と様子見が交錯する展開が予想されます。新発10年物国債利回りが2.6%台で高止まりするなか、金利上昇の恩恵を受ける金融株と、金利動向に振れやすい高PER株の物色の綱引きにも注目です。

出典: 日本経済新聞 / 三井住友銀行 マーケット

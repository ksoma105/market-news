前号以降に確認できた投資関連材料から、米金融政策、韓国の脱炭素投資、国際的な過剰生産対策、電子機器認証、米消費関連決算の5件をまとめました。発表された方針と、今後の採決・実施・需要動向に残る不確実性を分けて記載しています。

音声向け原稿

FRB議事要旨、国債市場ストレスへの備え強化を議論

米連邦準備制度理事会が10月7日に公表した9月15〜16日のFOMC議事要旨によると、参加者全員が政策金利を0.25ポイント引き上げ、3.75〜4.00%とすることを支持した。大半は年内にもう1回の利上げが適切になる可能性を見込んだ。また、一部参加者は米国債市場が現在は円滑に機能しているとしつつ、市場混乱に備えた戦略・情報発信・手段の強化を提案した。

影響が考えられる業種：銀行・証券、住宅・不動産、高バリュエーション株

注目点・リスク：高金利の長期化は融資採算を支える一方、住宅ローンや企業の資金調達負担を高める。市場ストレス対策は準備段階であり、国債購入など具体策の実施が決まったわけではない。

韓国、2035年までに1000兆ウォン規模の脱炭素戦略

韓国政府は10月7日、2035年までのエネルギー転換・脱炭素戦略「K-GX」を発表した。規模は1000兆ウォン、約7470億ドルで、200兆ウォンの財政支出と790兆ウォン超の気候金融を含み、別枠で民間投資220兆ウォンも掲げた。2030年までに再生可能エネルギー設備100ギガワット、2035年に電気・水素自動車を新車販売の70%超とする目標も示した。

影響が考えられる業種：再生可能エネルギー、蓄電池・自動車、鉄鋼・化学・半導体

注目点・リスク：設備投資と政策金融は関連企業の受注を支え得る一方、財政・金融・民間投資の区分には重なりがあり、総額を単純合算できない。技術の商用化、系統整備、資金配分の実行速度も不確実だ。

日米欧など15経済圏、製造業の構造的過剰生産への対処で共同声明

米通商代表部は10月7日、米国、日本、欧州連合など15経済圏の貿易担当相が、製造業の構造的な過剰生産能力と市場を歪める非市場的政策への対処を求める共同声明に署名したと発表した。中国、ブラジル、インドネシア、ロシア、サウジアラビア、南アフリカは署名国に含まれていない。

影響が考えられる業種：鉄鋼、自動車・EV、太陽光・電池、機械

注目点・リスク：今後、関税や補助金規律、輸入制限など各国の防衛措置が強まれば、価格と供給網に影響する可能性がある。ただし声明は協調方針で、対象品目や具体的措置、実施時期はまだ決まっていない。

米FCC、中国の試験所による電子機器認証を全面禁止へ採決

米連邦通信委員会は10月29日、スマートフォン、カメラ、コンピューターなど米国向け電子機器の試験を中国の試験所に認めない規則案を採決する。中国など米国の試験所を相互承認しない国の試験・認証機関を対象とし、採択された場合は2028年12月に発効する予定だ。FCCによると2025年は電子機器の82%が中国で試験され、米国内は4%未満だった。

影響が考えられる業種：電子機器、通信機器、試験・認証、物流

注目点・リスク：試験拠点の移転は認証期間とコストを押し上げる可能性がある一方、米国内や低リスク国の試験所には需要が移る可能性がある。現時点は採決前で、最終規則や移行措置は変更され得る。

Levi Strauss、関税還付と年末需要を追い風に通期利益予想を上方修正

Levi Straussは10月7日、通期の調整後1株利益予想を従来の1.46〜1.52ドルから1.54〜1.56ドルへ引き上げた。8月30日までの第3四半期に関税還付7900万ドルを受け、うち約6000万ドルを年内の販促に振り向ける。四半期売上高は4%増の16億1000万ドルだったが、直販事業の既存店売上高は横ばいで、米国販売は減少した。

影響が考えられる業種：衣料品、小売、物流・広告

注目点・リスク：還付と販促は短期利益・需要を支え得るが、基礎的な米国消費の弱さと燃料高が重しとなる。時間外取引では一時7%高の後、1.3%安となり、市場は持続性を慎重に見ている。

月曜夜は、NVIDIAとMediaTekの資本・技術提携、AIデータセンター冷却を巡る大型買収、設備投資がけん引するインド高成長の3つの動きをお伝えします。

NVIDIA、MediaTek転換社債に35億ドル投資—AI半導体連携を拡大

NVIDIAは31日、台湾MediaTekが発行する転換社債に35億ドルを投資したと発表しました。MediaTekはNVIDIAのNVLink Fusionを採用し、NVIDIAのラック規模AIシステムへ接続できるカスタムAIチップの開発基盤を提供します。両社はAI PC向けチップとAI搭載車のプラットフォームでも協業を拡大します。NVIDIAが自社技術を使う企業へ資金を供給する動きはAIエコシステムを広げる一方、循環的な資金調達への投資家の警戒も強めます。

出典: Reuters / 共同発表

SLB、データセンター冷却のKelvionを34億ドルで買収

エネルギー技術大手SLBは31日、データセンター向け冷却機器を手がけるKelvionを現金34億ドルで買収し、約7億ドルの債務も引き受けると発表しました。SLBはAI普及で増える電力・冷却需要を取り込み、データセンター向け事業の1ギガワット当たり収益機会を2倍超へ広げる計画です。統合事業では2028年に売上高45億〜50億ドル、調整後EBITDA7億〜8億ドルを目標とし、取引完了は2027年上期を見込みます。

出典: SLB / Reuters

インド4〜6月GDP、7.8%増—設備投資11.9%がけん引

インドの2026年度4〜6月期の実質GDPは前年同期比7.8%増となり、ロイター調査の予想7.1%を上回りました。政府統計では、総固定資本形成が11.9%増、個人消費が7.1%増、実質GVAが8.2%増。製造業は9.2%、金融・不動産・IT・専門サービスは12.1%伸びました。設備投資と内需が高成長を支える一方、約85%を輸入に依存する原油価格の上昇と通貨安が今後のインフレ・金融政策リスクです。

出典: インド統計・事業実施省 / Reuters

こんにちは。本号は、午前のアジア市場で広がった「リスクオン」の動きを軸に整理します。前日の米国株最高値を受け、3日の東京市場では日経平均株価が取引時間中として初めて6万8,000円台に乗せ、香港や中国本土の株式も大きく上昇しました。原動力は、決算と新製品発表が相次ぐ人工知能（AI）・半導体関連への資金集中です。米国では、アルファベットが800億ドル規模の大型増資を打ち出して希薄化への警戒が出る一方、ヒューレット・パッカード・エンタープライズ（HPE）の好決算がAIサーバー需要の強さを裏づけました。欧州では11日の欧州中央銀行（ECB）会合を前にインフレ再加速が確認されています。本号では、(1)日経平均の最高値更新とアジア株高、(2)アルファベットの大型増資、(3)HPE決算とAIチップ株、(4)ECBの利上げ観測、(5)金・原油と安全資産、の5本を取り上げます。

日経平均が初の6万8,000円台 — AI・半導体株が主導、アジア株は全面高

3日の東京株式市場で日経平均株価は急伸し、前場中ごろには前日比1,500円ほど高い6万8,200円台で推移して、取引時間中として初めて6万8,000円の大台に乗せました。前日2日は日中値幅が1,300円に達する乱高下の末に200円90銭安（約0.3%安）の6万6,734円24銭と3営業日ぶりに反落していましたが、この日は前日の米国株最高値を背景に、海外勢による株価指数先物や主力株への買いが優勢となりました。AI・半導体関連の一角に資金が集中し、市場では「持たざる恐怖」とも評される強い物色意欲が指摘されています。アジア全体でも株高が広がり、香港ハンセン指数が一時2.4%高、中国本土の代表的な株価指数であるCSI300も約1.5%高の4,914前後で取引を終えました。一方、為替のドル円相場は1ドル159円台後半で推移しており、市場は3日夕に予定される植田和男・日銀総裁の講演を見極めようとしています。

アルファベットが800億ドルの大型増資計画 — AI投資の資金調達、希薄化への警戒も

米グーグルの親会社アルファベットが、総額800億ドル規模の大型増資を打ち出しました。報じられている内訳は、著名投資家ウォーレン・バフェット氏率いるバークシャー・ハサウェイへの100億ドルの第三者割当（市場価格より約6%割安）、300億ドルの公募増資、そして第3四半期に始める400億ドルの市場内売り出し（ATM）です。調達資金は急拡大するAI投資に充てられます。同社の2026年の設備投資は1,800億〜1,900億ドルと前年のほぼ2倍に膨らむ見通しで、2027年もさらに増える可能性が示されています。発表を受けて2日のアルファベット株は一時4%近く下落しました。AI需要が実際の受注と利益成長を生む一方で、急激な投資拡大が増資による株式の希薄化や利益計上の後ずれにつながるとの懸念が交錯した格好です。AI関連の巨額投資が、企業の資金調達のあり方にも影響を及ぼし始めています。

出典: Investing.com / The Motley Fool

HPE決算が過去最大級の上振れ、株価は最良の1日 — マーベル・ブロードコムも最高値圏

ヒューレット・パッカード・エンタープライズ（HPE）の四半期決算が市場予想を大きく上回り、2日の株価は約19%上昇して同社として過去最大の上げ幅を記録しました。調整後の1株利益は79セント（予想53セント）、売上高は106.8億ドル（予想97.9億ドル）で前年同期比40%増と急伸し、けん引役のサーバー事業は売上高54.5億ドル（予想46.6億ドル）とAI関連需要が想定を圧倒しました。通期の1株利益見通しも従来の2.30〜2.50ドルから3.35〜3.45ドルへ大幅に引き上げています。AI物色の裾野は広がっており、データセンター向け通信半導体を手がけるマーベルはエヌビディアのフアンCEOが「次の1兆ドル企業になり得る」と評したことを受けて約28%急騰、同業のブロードコムも約5%高で最高値を更新しました。台北での見本市「コンピューテックス」で相次いだ新製品発表が、半導体・サーバー関連株への買いを一段と後押ししています。

出典: CNBC / The Motley Fool

ECB、11日に利上げの公算 — ユーロ圏5月インフレが3.2%へ再加速

欧州中央銀行（ECB）が11日に開く理事会で、追加利上げに踏み切るとの見方が強まっています。ユーロ圏の5月の消費者物価（HICP）は前年同月比3.2%上昇と、4月の3.0%から伸びが加速しました。エネルギー以外への広がりが特徴で、変動の大きい食品とエネルギーを除くコア指数は2.5%へ上昇、サービス価格は3.0%から3.5%へと大きく加速して1年余りで最も高い水準となっています。主要国別では、ドイツが2.7%、フランスが2.8%、イタリアが3.3%、スペインが3.6%でした。エネルギー価格は10.9%高と高止まりが続いています。物価上昇圧力がエネルギーから賃金に左右されやすいサービス分野へ波及している点が、ECBの利上げ観測を後押ししています。日米欧で金融政策の方向感が分かれるなか、欧州の動向は為替や債券市場にも影響を及ぼしそうです。

出典: Euronews / GMK Center

金は4,480ドル近辺へ反落、原油は高止まり — リスクオン優勢も地政学リスクくすぶる

株式市場でリスク選好が強まるなか、安全資産には方向感を探る動きがみられます。金スポット価格は1トロイオンス4,481ドル近辺と、前日に4,500ドルを回復した水準からやや反落しました。米国とイランの停戦交渉が停滞し、地政学リスクと物価上振れへの警戒が下支えとなる一方、資金が株式へ向かう流れが上値を抑えています。原油市場では北海ブレント先物が1バレル95ドル前後で高止まりしています。イランがイスラエルのレバノンでの軍事行動を理由に米国との連絡を停止したと伝わり、ホルムズ海峡などの供給途絶への警戒がくすぶります。市場は7日に予定されるOPECプラスの閣僚会合での増産姿勢にも注目しています。株高の裏で地政学リスクと資源高が並存する構図が続いており、当面はインフレ動向と中東情勢の両にらみの展開となりそうです。

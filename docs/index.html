中国の工業利益、9月は14.4%増　業種間の格差続く

中国国家統計局のデータによると、一定規模以上の工業企業の利益は9月に前年同月比14.4%増え、8月の4.2%増から加速した。1〜9月は15.5%増で、1〜8月の15.7%増からは小幅に鈍化した。

影響が考えられる業種：中国関連株、電子機器、製造装置、家具

注目点・リスク：1〜9月のコンピューター・通信・電子機器は103.8%増だった一方、家具は51.3%減。AI・ハイテク分野と内需型産業の二極化が続く。対象は年商2,000万元以上の企業で、中国企業全体を直接示す統計ではない。

韓国中銀、AI投資減速なら半導体輸出最大1,000億ドル減と試算

韓国銀行は、米大手テック企業のAI設備投資が2027年に鈍化する悲観シナリオで、韓国の半導体輸出が従来想定より500億〜1,000億ドル減り、GDP成長率を約0.4ポイント押し下げ得ると試算した。

影響が考えられる業種：半導体、製造装置、メモリー、韓国輸出

注目点・リスク：半導体単価が10%下落するとの仮定を置いたストレスシナリオで、基本予測ではない。半導体は韓国輸出のおよそ半分を占めるため、米テック企業の設備投資計画、AI需要、価格サイクルの変化が焦点となる。

日本の企業向けサービス価格、9月は3.7%上昇

日銀の企業向けサービス価格指数は9月に前年同月比3.7%上昇し、改定後の8月の3.5%上昇から伸びが拡大した。日銀は、賃金コストがサービス価格に波及しているかを基調的な物価判断の材料としている。

影響が考えられる業種：サービス、物流、広告、不動産、金融

注目点・リスク：サービス価格の持続的上昇は利上げ判断を後押しし得る一方、個別品目や一時要因を含むため、単月の数字だけで政策変更は決まらない。賃金、消費者物価、景気との組み合わせを確認する必要がある。

豪AirTrunk、シドニーのデータセンター拡張に42.5億豪ドル融資

豪データセンター企業AirTrunkは、シドニー西部のSYD3拡張向けに42億5,000万豪ドル、約29億8,000万米ドルのグリーンローンを確保した。32の金融機関が参加し、完成は2028年半ばを予定する。

影響が考えられる業種：データセンター、銀行、建設、電力設備

注目点・リスク：同社の世界の債務コミットメントは約384億豪ドルに達する。AI計算需要を取り込む大型投資だが、資金調達費用、電力接続、建設遅延、需要見通しの変化が収益性を左右する。

Reuters ・ 公開 2026-10-27 11:25 JST

スペイン、データセンター規制案を緩和　対象を10MW超へ

スペイン政府はデータセンター規制案を修正し、主な要件の対象を1メガワット超から10メガワット超へ引き上げた。稼働前に確保した再生可能エネルギー契約を認める期間も18カ月から36カ月へ延長した。

影響が考えられる業種：データセンター、再生可能エネルギー、電力網、建設

注目点・リスク：電力の80%を時間単位で再生可能エネルギーと一致させる要件は残るが、条件付きで最長5年の移行期間が認められる。投資負担は軽くなる一方、電力網の制約と環境目標の実効性が焦点となる。

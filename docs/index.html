世界的な金利上昇、円相場、欧州金融政策、AI・IT需要、米中関係など、株式投資への波及が考えられる最新ニュース6件をまとめました。

米・日国債利回りが数十年ぶりの高水準、株式はAI期待で底堅さ

9月25日の市場では、米10年国債利回りが5.2297%と2007年以来、日本の10年国債利回りが3.121%と1996年以来の高水準を付けた。一方、MSCI世界株指数は同日時点で0.22%上昇し、AI関連への期待を背景に週間では8月初旬以来の好調さとなった。数値は9月25日のReuters配信とUOB Kay Hianの市場資料で確認した。

影響が考えられる業種：銀行・保険、半導体・AI、住宅・不動産

注目点・リスク：長期金利上昇は金融機関の利ざや要因になり得る一方、債券評価損や資金調達コスト上昇も招く。AI期待が金利負担を上回り続けるか、週明けの債券・ハイテク株の反応が焦点。

Reuters（Fidelity配信） ・ UOB Kay Hian

円が反発、日米が為替介入時の姿勢を共有との説明

9月25日のニューヨーク市場で円は対ドルで上昇し、Business RecorderのReuters配信ではドル円が157円台まで下落した。日本側が、7月の共同介入を支えた日米の姿勢が今も維持されていると説明したことが材料視された。原油は1%以上下落したが、国際価格はなお1バレル100ドル超で、インフレ圧力は残る。

影響が考えられる業種：輸出型製造業、自動車、航空・小売

注目点・リスク：円高は輸入コストを和らげ得る一方、輸出企業の円換算利益には逆風となり得る。介入観測だけで流れが持続するか、米金利と中東情勢の変化が不確実要因。

Reuters（Business Recorder配信）

ノルウェー中銀が政策金利を4.50%へ引き上げ

ノルウェー銀行は9月24日、政策金利を4.25%から4.50%へ引き上げた。中銀はインフレが数年にわたり目標を上回り、企業コストの上昇が物価を高止まりさせる可能性を指摘。必要なら追加利上げの用意がある一方、インフレ鈍化や雇用悪化なら金利見通しが下がり得るとも説明した。

影響が考えられる業種：銀行、住宅・不動産、エネルギー

注目点・リスク：高金利長期化は銀行収益を支える面と、住宅・企業需要を冷やす面がある。原油・ガス価格、クローネ相場、基調インフレが次回11月5日の判断を左右する。

Norges Bank ・ UOB Kay Hian

Meta、AIモデルAPIを世界で一般提供　Muse Codeもベータ終了

Metaは9月24日のConnect 2026総括で、Meta Model APIの世界での一般提供、Muse Codeのベータ終了とWindows対応、30BパラメーターのオープンウェイトモデルMuse Glimmerなどを発表した。VR Glassesは2027年春に出荷予定で、対応SDKは先行提供される。

影響が考えられる業種：AIソフトウェア、クラウド、半導体・デバイス

注目点・リスク：開発者接点の拡大は推論需要やエコシステム形成につながり得るが、企業採用・有料転換・運用コストは未確認。新製品の収益寄与時期と競合APIとの差別化が焦点。

Meta Developers ・ UOB Kay Hian

TD SYNNEX、AI・データセンター需要で四半期売上が37.7%増

TD SYNNEXが9月24日に発表した2026年度第3四半期売上高は215.58億ドルで前年同期比37.7%増、希薄化後EPSは5.18ドル、調整後EPSは5.68ドルだった。会社はAIの本番導入とデータセンター近代化を追い風に挙げた一方、粗利益率は前年の7.22%から6.61%へ低下し、営業キャッシュフローは9.17億ドルの流出となった。

影響が考えられる業種：IT流通、サーバー・データセンター、サイバーセキュリティ

注目点・リスク：売上成長はAIインフラ需要の強さを示すが、低下した粗利率と運転資本によるキャッシュ流出は注視が必要。第4四半期の売上見通し218億〜226億ドルに対する進捗が焦点。

TD SYNNEX ・ UOB Kay Hian

米中首脳会談、AI・通商・台湾で目立った突破口なし

Reutersは9月25日、前日にホワイトハウスで行われたトランプ米大統領と習近平中国国家主席の会談について、象徴的な演出は大きかった一方、AI、通商、台湾、イラン戦争を巡る明確な突破口は確認されなかったと報じた。対話継続自体は政策の急激な悪化を抑える材料だが、主要な対立点は残った。

影響が考えられる業種：半導体、電子部品、機械・自動車

注目点・リスク：関税や先端技術規制の不確実性が続けば、設備投資・供給網計画の重荷になり得る。共同文書や実務協議で具体策が示されるかが次の確認点。

音声向け原稿

日本の8月実質消費、前年比3.1%減で9カ月連続マイナス

総務省が10月9日に公表した8月の家計調査で、実質消費支出は前年同月比3.1%減と、市場予想の3.6%減より小幅ながら9カ月連続で減少した。季節調整済みの前月比は0.1%増で、予想の0.5%増を下回った。一方、8月の実質賃金は8カ月連続で増加しており、賃金改善が消費へ波及するかが焦点となる。

影響が考えられる業種：小売・外食、消費財、銀行

注目点・リスク：消費の弱さは内需企業の売上や利上げ判断に影響する可能性がある。ただし、前年比の落ち込みは予想より小さく、実質賃金の増加が今後の支出を支えるかを確認する必要がある。

アジア株は軟調、AI投資懸念と米長期金利が重荷

10月9日のアジア時間に、MSCIアジア太平洋株指数（日本除く）は0.16%下落し、週間では1%超の下げに向かった。日経平均は1%超下落。AI関連投資の採算への懸念に加え、米10年国債利回りが5.226%と約24年ぶりの高水準付近にあること、原油高が株式の重荷となった。韓国と台湾市場は休場だった。

影響が考えられる業種：半導体・AI関連、輸出製造、金融

注目点・リスク：高金利は成長株の評価を圧迫し、原油高は幅広い企業のコスト要因になり得る。ただし、休場市場があり地域全体の需給を測りにくく、AI投資の収益性や金利の持続性を見極める必要がある。

Nvidia出資のFirmus、需要不足で豪50億ドルIPOを撤回

Nvidiaが出資する豪AIデータセンター運営会社Firmusは、投資家需要が弱かったため50億豪ドル規模のIPOを撤回し、民間資金を調達する方針に切り替えた。予定価格は1株11豪ドル、株式価値は306億豪ドルで、8月時点の評価額105億豪ドルの約3倍。メルボルンとシンガポールの2拠点に加えアジア太平洋で5拠点を計画する一方、債務は約300億豪ドルと報じられた。

影響が考えられる業種：データセンター、半導体・AIインフラ、投資銀行

注目点・リスク：案件撤回はAIインフラ投資でも資本負担と採算への選別が強まったことを示す可能性がある。高い評価額、巨額債務、増設計画の実行力を民間調達で補えるかが焦点となる。

原油反落、イラン協議進展で供給懸念がやや後退

10月9日2時20分GMT時点で、北海ブレント先物は0.7%安の1バレル103.53ドル、米WTI先物は0.6%安の90.97ドルだった。米大統領が11月3日の選挙前にイランを攻撃しない意向を示し、協議が生産的だと述べたことで供給不安がやや後退した。一方、戦争前のホルムズ海峡は世界の石油・燃料輸送の約20%を担い、ハリケーンで米メキシコ湾の生産約130万バレル、現行生産の62.9%が停止した。

影響が考えられる業種：石油・ガス、航空・物流、化学

注目点・リスク：外交進展は価格上昇圧力を和らげ得るが、海峡の供給リスクと米湾岸の停止は残る。政治発言や天候で価格が急変しやすく、企業コストへの波及は不確実性が大きい。

インドのAIデータセンター計画、住民反発と水資源制約が浮上

Amazonが2030年までにインドのAIインフラへ210億ドルを投じる計画を進める中、ムンバイ近郊では54エーカーのデータセンター計画に住民が水・電力・騒音を理由に反対している。Amazonと地元当局は専用の電力・水供給で公共インフラに負担をかけないとしている。S&P Globalは、インドのデータセンターの60〜80%が今後10年に高い水ストレスへ直面する可能性があると推計した。

影響が考えられる業種：データセンター、電力・水インフラ、建設

注目点・リスク：AI需要は設備投資を押し上げ得る一方、許認可、住民合意、水・電力の確保が開業時期とコストを左右する。企業側の対策が実際に地域負担を抑えられるかを継続確認する必要がある。

金は1オンス4,169ドル、ドル一服と金利低下で反発

10月9日1時37分GMT時点で、現物金は0.9%高の1トロイオンス4,169.32ドル、米金先物は0.9%高の4,194.40ドルとなった。ドル高が一服し、米10年国債利回りが2日続けて低下したことが支えた。CMEの指標では、10月の利上げ確率が18%、12月の利上げ確率が82%と織り込まれていた。

影響が考えられる業種：貴金属鉱山、宝飾、資産運用

注目点・リスク：金はドルと実質金利、地政学リスクへの感応度が高く、金融政策観測の変化で振れやすい。2カ月ぶり安値からの反発が持続するかは、米金利とドルの方向次第となる。

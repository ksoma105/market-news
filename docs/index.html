米国の暗号資産規制、カナダの空港運営・投資策、アルゼンチン予算、スペインのAIエージェント侵害、ブラジルの自動車投資、米銀の貸出再編の6件をお伝えします。

米上院、暗号資産包括法案を前進できず—関連株約9%安

米上院は9月15日、暗号資産の包括的な規制枠組みを設ける「Clarity Act」の審議入りに必要な60票を確保できませんでした。共和党議員4人も反対に回り、中間選挙前の議会休会を控えて法案の先行きは不透明です。市場ではCoinbaseとCircleがそれぞれ約9%下落し、ビットコインは約4%安の7万5,908ドルとなりました。

出典: Reuters / AP

カナダ、4大空港運営に民間資金—投資公約は約5000億加ドル

カナダ政府はトロント、モントリオール、バンクーバー、カルガリーの4大空港について、土地・資産の公的所有を維持したまま、長期運営権を通じて民間資金を導入します。政府は国内年金基金の強い関心を見込み、外国投資には安全保障審査も実施する方針です。同日の投資サミットでは、国内向けの新規投資公約が約5,000億カナダドルに達したと発表しました。

出典: Reuters / カナダ首相府

アルゼンチン、2027年成長率4%・インフレ18%の予算案

アルゼンチン政府は9月15日、2027年予算案を議会に提出しました。実質GDP成長率を今年見込みの3%から4%へ高め、貿易黒字は150億ドル超を予測。年間インフレ率は今年見込みの29%から18%へ低下するとしています。大統領選を2027年10月に控えるなか、法案は予算委員会での審議を経て本会議に進みます。

出典: Reuters / El Cronista

スペイン当局、AIエージェント実行の初の個人情報侵害を受理

スペインデータ保護庁（AEPD）は、AIエージェントが実行したとされる個人データ侵害の初の届け出を受理しました。既知の大規模言語モデルを使うエージェントが脆弱性を探し、システムへのアクセス後に個人データを改変し、請求書を閲覧したとされています。情報はなお審査中で、利用モデルや被害組織は公表されていません。

出典: Reuters / EFE

Renault・Geely、ブラジルに3.19億ユーロ追加投資

RenaultとGeelyは合弁事業を通じ、ブラジルに3億1,900万ユーロを追加投資します。2025〜2027年の累計投資額は8億9,900万ユーロに拡大。共同プラットフォームを使うRenaultの新型電動車を2027年初めから生産するほか、Geelyの電気自動車EX2も2026年12月に現地生産を始める計画です。

出典: Reuters / Cinco Días

Truist、55億ドルの自動車ローン売却—準プライム撤退

米銀Truist Financialは55億ドルの自動車ローンを売却し、準プライム自動車融資から撤退します。純収入は52億ドルを見込み、貸倒引当金5億3,500万ドルの戻し入れも予定。同行は4〜6月期に船舶・RV融資を停止し、自動車融資も縮小しており、収益性の低い非中核事業を見直す再編を加速させています。

出典: Reuters / Banking Dive

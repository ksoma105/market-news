IEA、残る約1億バレルの放出加速　ディーゼル2,000万バレル超

国際エネルギー機関（IEA）は、3月に決めた緊急備蓄放出のうち、残る約1億バレルを各国の事情に応じて速やかに放出し、ディーゼル2,000万バレル超をできるだけ早く市場へ供給することで合意した。IEAによると、これまでの放出は約3億3,000万バレルで、当初の総量4億バレルを最終的に上回る見込みである。背景には、ディーゼルを中心とする石油市場の逼迫がある。

影響が考えられる業種：石油精製、運輸・物流、化学

注目点・リスク：備蓄放出は供給逼迫と燃料費を和らげる可能性がある。ただし実施時期は各国事情に左右され、2,000万バレル超という規模で価格圧力をどこまで抑えられるかは不確実である。

UniCredit、Commerzbank支配権へECB承認　年末に議決権約50%

UniCreditは、Commerzbankへの出資比率を30%超へ引き上げ、上限なく追加取得することについて欧州中央銀行（ECB）の承認を得た。残る規制手続きと条件が年末ごろに整えば、UniCreditは議決権の約50%を持ち、同行を支配できる見通しである。Reutersによると、買収提案は450億ユーロ規模で、欧州の国境を越えた銀行再編として金融危機後最大級となる。

影響が考えられる業種：銀行、証券、企業向け金融

注目点・リスク：統合期待は欧州銀行再編を促す可能性があるが、支配権取得は残る条件の充足が前提である。ドイツ政府とCommerzbank側の反対、完全統合の時期、資本・システム統合コストを確認する必要がある。

仏独、EU自動車CO2目標90%案で接近　英国を域内扱いも

フランスとドイツは、2035年の新車二酸化炭素排出量を2021年比で90%減らす一方、低炭素鋼や代替燃料による追加相殺を求めない共同案で合意に近づいている。自動車分野の「Made in Europe」では、英国など2020年1月1日時点でEU単一市場に参加していた欧州の相手国を、相互主義とEUの通商防衛策への連携を条件に含める案も示された。案は未確定で、他のEU加盟国と欧州議会の承認が必要である。

影響が考えられる業種：自動車、電池、鉄鋼

注目点・リスク：規制緩和は欧州自動車メーカーの対応負担を軽くする可能性がある一方、電動化投資や低炭素素材需要の前提を変え得る。仏独案は最終決定ではなく、英国の通商政策との整合条件も残る。

英8月GDPは0.1%増　生産0.8%増、サービスは横ばい

英国立統計局によると、8月の実質国内総生産は前月比0.1%増え、Reuters調査の市場予想である0.1%減を上回った。生産は0.8%増、サービスは横ばい、建設は0.2%減だった。5〜8月ではなく、5月までの3カ月と比べた6〜8月のGDPは0.7%増で、前年同月比では8月が2.1%増となった。統計局は、初期推計が今後上下に改定され得ると注意を促している。

影響が考えられる業種：製造業、情報サービス、建設

注目点・リスク：予想を上回る成長は企業活動の底堅さを示す可能性があるが、サービス横ばいと建設減少は部門差の大きさを示す。改定リスクと、エネルギー価格上昇が9月以降の需要へ与える影響を確認する必要がある。

ブラジル決選投票、財政案の具体性乏しく　債務はGDP比82.9%

ブラジル大統領選の決選投票を前に、ルラ氏とボルソナロ氏は家計に配慮した財政方針を掲げるが、債務抑制の具体策は限られている。Reutersによると、政府総債務は国内総生産比82.9%で、ルラ政権の今期中に10ポイント超上昇した。ボルソナロ氏は18カ月で基礎的財政収支をGDP比1.5%改善するとしているが、手段は説明していない。ルラ氏は低所得層への負担を避けながら、より緩やかな財政健全化を主張している。

影響が考えられる業種：銀行、建設・インフラ、公益

注目点・リスク：選挙後の財政運営は国債利回り、通貨、公共投資に影響する可能性がある。ただし両陣営の案は選挙公約の段階で、義務的支出の大きさを踏まえた制度設計と議会での実現性が不透明である。

中国人民銀行総裁、世界的不均衡は為替調整だけで解消せず

中国人民銀行の潘功勝総裁は、バンコクで開かれた20カ国・地域の財務相・中央銀行総裁会議で、世界経済の不均衡を評価する際は経常収支や為替レートだけでなく、金融経路を通じた資金移動も見る必要があると述べた。為替調整だけでは不均衡を解決できず、赤字国と黒字国の双方が協力し、動的な均衡を目指すべきだとの考えを示した。

影響が考えられる業種：銀行、輸出入、為替関連サービス

注目点・リスク：発言は人民元政策や国際協調を巡る議論の方向性を示すが、具体的な政策変更の発表ではない。今後の為替運営、内需策、貿易黒字を巡る各国との協議を確認する必要がある。

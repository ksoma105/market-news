2026/11/10（火）12:00 JST ・ 2026-11-10-1200

火曜午前に公表された経済指標から、日本の家計支出、中国の貿易、英国の消費動向を整理しました。

音声向け原稿

日本の9月実質家計支出、前年比6.8%減　2020年9月以来の大幅減

総務省が11月10日に公表した9月の家計調査によると、2人以上世帯の消費支出は1世帯当たり28万9,536円で、物価変動を除いた実質では前年同月比6.8%減少した。減少は10カ月連続で、落ち込みは2020年9月以来の大きさだった。季節調整済みの前月比も実質2.8%減となり、市場予想の前年同月比3.1%減、前月比0.3%増をともに下回った。悪天候も外出や支出を抑えたとみられる。

影響が考えられる業種：小売、外食・旅行、耐久消費財

注目点・リスク：家計消費の弱さが続けば、個人消費を軸にした景気回復は鈍る可能性がある。ただし、単月の数字には天候要因が含まれるため、賃金の伸びが今後の支出に波及するかを複数月で見極める必要がある。

総務省統計局 / Reuters ・ 公開 2026-11-10 09:04 JST

中国10月輸出は35.2%増　輸入は41.6%増、累計黒字1兆ドル超

中国の10月の輸出は米ドル建てで前年同月比35.2%増の4,123億3,000万ドルとなり、市場予想の33.5%増を上回った。輸入は41.6%増の3,070億5,000万ドルで、予想の32%増を大きく上回った。月間貿易黒字は1,052億8,000万ドルに縮小した一方、1〜10月の累計黒字は1兆430億ドルに達した。AIインフラ関連製品への需要が輸出を支えている。

影響が考えられる業種：半導体・電子部品、機械、海運・資源

注目点・リスク：輸出の高い伸びはアジアの技術供給網や物流需要を支える可能性がある。一方、輸入の伸びが輸出を上回り、月間黒字は市場予想の1,258億ドルを下回った。AI投資循環の減速や、巨額黒字を巡る通商摩擦が先行きのリスクとなる。

Reuters / Trading Economics ・ 公開 2026-11-10 11:42 JST

英国10月小売支出は1.5%増　ブラックフライデー前で伸びは限定的

英国小売協会の調査によると、10月の店舗支出は前年同月比1.5%増と、9月の1.3%増から加速し、6月以来の高い伸びとなった。食品は3.2%増だったが、非食品は横ばいだった。別のBarclays調査ではカード支出が2.3%増と、2025年7月以来の高い伸びを記録した。生活必需品は3.1%増で、燃料支出の22.7%増が押し上げた一方、非必需品は1.9%増だった。

影響が考えられる業種：小売、決済、食品、燃料販売

注目点・リスク：名目支出の底堅さは年末商戦への追い風となり得るが、値上がりの影響を含むため販売数量の強さとは限らない。大型品の購入先送り、燃料価格、家計コストの上昇が、ブラックフライデー後の需要を左右する。

音声向け原稿

米10月CPIは前月比0.4%上昇　予想上回り12月の利上げ観測強まる

米労働統計局が11月10日8時30分（米東部時間）に公表した10月の消費者物価指数は、季節調整済みで前月比0.4%上昇し、Reuters集計の市場予想0.3%を上回った。食品とエネルギーを除くコア指数も0.3%上昇し、市場予想0.2%を上回った。住居費は0.3%、食品は0.5%、エネルギーは0.7%上昇した。2025年10月は政府閉鎖で価格データを収集できなかったため、前年比は公表されていない。発表後は米10年国債利回りが前日の4.88%から一時5.01%へ上昇し、株式市場には重荷となった。

影響が考えられる業種：銀行・保険、不動産・住宅、消費関連

注目点・リスク：インフレの上振れが続けば、米連邦準備制度理事会が12月に利上げを再開し、借入コストを押し上げる可能性がある。一方、前年比が欠ける特殊な統計であり、10月の個人消費支出物価指数や11月雇用統計で持続性を確認する必要がある。

米労働統計局 / Reuters配信 / AP ・ 公開 2026-11-10 22:30 JST

ウクライナ攻撃、ロシア製油能力の約30%に影響　実処理は日量最大20万トン減

Reutersが11月10日に報じた業界関係者2人の推計によると、10月末以降のウクライナによるドローン攻撃で影響を受けたロシア製油所の公称能力は日量約30万トン、220万バレルで、国内一次処理能力約93万トンの約3割に相当する。過去1週間に主要35製油所のうち9カ所で操業障害や緊急事態が発生し、実際の原油処理量は最大日量20万トン減った可能性がある。国際エネルギー機関も、攻撃の長期化でガソリン生産が2025年比20%減、軽油生産が約30%減と推計している。

影響が考えられる業種：石油精製、海運・物流、農業・運輸

注目点・リスク：製品供給の不足はロシア国内の燃料価格や輸出余力に波及する可能性がある。ただし、30%は停止量ではなく影響を受けた設備の公称能力であり、修理の進捗や迂回生産によって実際の供給減は変わる。

Reuters / 国際エネルギー機関 ・ 公開 2026-11-10 21:17 JST

日本の投資家、10月は海外債券を4,939億円買い越し　3カ月ぶり

財務省が11月10日に公表した指定報告機関ベースの月次統計によると、日本の投資家は10月に海外債券を4,939億円買い越し、7月以来3カ月ぶりの買い越しとなった。内訳は中長期債が4,572億円、短期債が367億円の買い越しだった。海外株式も1兆4,600億円を買い越し、3月以来の大きさとなった。一方、2026年累計では海外債券を4兆1,600億円売り越している。

影響が考えられる業種：生命保険、銀行・証券、資産運用

注目点・リスク：米長期金利の低下局面やAI関連株の変動を受け、安全資産需要が戻った可能性がある。ただし、この統計は指定報告機関ベースで国際収支統計より報告範囲が狭く、単月の買い越しだけで恒常的な資金回帰とは判断できない。

音声向け原稿

日銀総裁、基調物価2%定着へ追加利上げ方針を維持

日銀の植田和男総裁は10月6日、基調的な物価上昇率が2%に近づき、金融環境はなお緩和的だとして、経済・物価・金融情勢に応じて政策金利を引き上げる方針を改めて示した。9月に政策金利を1.25%程度へ引き上げた後も緩和的な環境は維持されると説明し、中東情勢、AI関連需要、円相場が物価を上振れさせるリスクを挙げた。

影響が考えられる業種：銀行・保険、不動産、輸出・輸入企業

注目点・リスク：追加利上げは金融機関の利ざやや企業の資金調達コストに影響する可能性がある。10月29〜30日の会合で示す物価見通しと、原油・円相場を踏まえた利上げ時期を確認したい。

FRB、銀行監督を5地域体制へ再編

米連邦準備制度理事会（FRB）のボウマン銀行監督担当副議長は10月6日、銀行監督を5つの地域に再編し、各地域の責任者が監督活動を統括する方針を示した。固定額の資産規模で決まる規制区分についても、インフレや経済成長を反映して5年ごとに更新する仕組みを検討する。シリコンバレー銀行破綻の検証で指摘された意思決定の遅れと責任の曖昧さに対応する。

影響が考えられる業種：米銀行、地域金融、金融規制対応サービス

注目点・リスク：規制区分の見直しは成長する銀行の負担を軽減し得る一方、監督の迅速化とリスク管理の実効性が両立するかは未確定である。具体的な閾値、導入時期、資本・流動性規制への波及を注視する必要がある。

Marvell、2028年度売上高見通しを約200億ドルへ引き上げ

Marvell Technologyは10月6日、AI向けカスタム半導体とデータセンター需要を背景に、2028年度の売上高見通しを従来の180億ドルから約200億ドルへ引き上げた。2031年度は700億〜900億ドルを見込み、中間値800億ドルはVisible Alpha集計の市場予想468億5000万ドルを大きく上回る。発表後の同社株は約7%上昇した。

影響が考えられる業種：半導体、データセンター、光通信・ネットワーク機器

注目点・リスク：長期見通しはAI設備投資と大口顧客の自社設計チップ需要が続くことを前提としている。巨額目標の達成確度、顧客集中、競合、設備投資サイクルの反転が主なリスクとなる。

Google、英Playストア手数料巡る10億ポンド超の集団訴訟に反論

英国で10月6日、GoogleのPlayストア手数料を巡る10億ポンド超、約13億3000万ドルの集団訴訟が始まった。原告側は2015年から2026年7月までの購入者約2000万人を代表し、最大30%の手数料が消費者へ転嫁されたと主張する。GoogleはAndroidには選択肢と競争があり、請求には根拠がないとして争っている。

影響が考えられる業種：アプリ配信、モバイルゲーム、デジタル広告

注目点・リスク：原告の主張は確定事実ではなく、Googleは責任を否定している。判決や和解が手数料体系、代替課金、開発者収益にどこまで影響するかが焦点で、損害額も今後の司法判断に左右される。

欧州の再エネ設備8547システム、ネット公開で制御リスク

オランダの研究者は10月6日、欧州35カ国の太陽光・風力発電所に結び付く8547の管理システムがインターネットから到達可能だったと報告した。内訳は太陽光7942、風力605で、約181拠点では完全な制御が可能だった恐れがある。研究者は運営者に管理画面を直ちに公開ネットワークから外すよう求めた。

影響が考えられる業種：再生可能エネルギー、電力網、サイバーセキュリティ

注目点・リスク：発見数は研究者が特定できた範囲であり、実際の侵害や停止が確認されたことを意味しない。運営者の是正状況、各国当局の対応、分散型電源の遠隔管理基準を確認する必要がある。

Reuters ・ Modat / NCSC-NL ・ 公開 2026-10-06 15:39 UTC

Anthropic、強力なAIモデルの防御目的アクセスを拡大

Anthropicは10月6日、審査済みのサイバーセキュリティ専門家が安全制限を緩めた最新モデルを使えるCyber Verification Programを拡充した。同社によると、Project Glasswingの提携先は4〜7月に12万9000件以上の検証済み脆弱性を発見し、うち3万3000件超は重大または高深刻度だった。新制度は防御、認可済み侵入試験、重要インフラ向けの3段階で審査する。

影響が考えられる業種：サイバーセキュリティ、AI基盤、重要インフラ

注目点・リスク：脆弱性件数はAnthropicと限られた提携先の自己申告を基にし、同社自身も過少集計の可能性を示している。防御能力の向上と同時に、制限を緩めたモデルの悪用防止、審査・監査の実効性が課題となる。

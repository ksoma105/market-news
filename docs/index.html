米財務省、イラン取引を続ける外国金融機関へ無通告制裁を警告

米財務省外国資産管理局（OFAC）は10月5日、イラン政府や同国の金融部門などとの制裁対象取引を直ちに停止するよう外国金融機関へ警告した。違反すれば事前通知なしで制裁対象となる可能性があり、米国でのコルレス口座・支払口座の開設禁止や厳しい利用制限、民事・刑事上の措置につながり得る。デジタル資産、金、航空、海運を介した取引もリスク例に挙げた。

影響が考えられる業種：銀行・決済、海運・商社、石油・商品取引

注目点・リスク：子会社や第三国拠点、暗号資産を通じた間接取引にも点検範囲が広がる。取引相手の実質所有者が見えにくい場合があり、制裁が無通告で発動される可能性を踏まえた与信・決済管理が焦点となる。

Lucidの7〜9月納車3806台、市場予想を下回る

高級EVメーカーのLucid Groupは、9月30日までの四半期に3806台を納車し、Visible Alpha集計の市場予想4687台を下回った。生産は2954台で予想3709台に届かず、前四半期の4774台から38%減少した。一方、納車は生産を852台上回り、既存在庫を販売へ振り向けた。年初来納車は1万852台で、通期市場予想約1万7070台に達するには10〜12月期に約6200台が必要となる。

影響が考えられる業種：電気自動車、車載電池・部品、EV販売金融

注目点・リスク：在庫圧縮はキャッシュフロー改善に寄与し得るが、必要な10〜12月期納車台数は過去最高の5345台を上回る。需要回復の具体的な数量、生産縮小後の固定費負担、14億ドルのキャッシュフロー改善計画の進捗を確認したい。

Mattel株主Ariel、売却を含む戦略的選択肢の検討を要求

Mattel株を5.4%保有するAriel Investmentsは10月5日、独立系財務アドバイザーを起用し、会社売却を含む戦略的選択肢を検討するよう取締役会に求めた。Arielは現行の上場会社としての構造では株価が著しく過小評価されていると主張した。Mattelは株主の意見を検討すると表明したが、正式な売却手続きの開始や買い手の存在は確認されていない。

影響が考えられる業種：玩具、映画・キャラクターライセンス、小売

注目点・リスク：経営トップ交代期に株主圧力が強まり、資本政策や事業再編への期待で株価が振れやすい。戦略的検討は提案段階であり、取引成立を前提にせず、年末商戦の販売動向と取締役会の対応を見極める必要がある。

C.H. Robinson、RXOを58億ドルで買収へ

米物流大手C.H. Robinsonは、貨物仲介のRXOを株式価値58億ドルで買収することで合意した。RXO株1株につき現金17.25ドルとC.H. Robinson株0.0856株を交付し、発表前終値に29%上乗せした約30.25ドルに相当する。統合後の企業価値は250億ドル超となる見通しで、会社は2年以内に年間3億ドルのコスト相乗効果を見込む。取引完了は規制・株主承認を条件に2027年上期を予定している。

影響が考えられる業種：貨物仲介、トラック輸送、ラストマイル配送

注目点・リスク：規模拡大による調達力と効率化が期待される一方、追加借り入れによるレバレッジ上昇、統合費用、規制審査がリスクとなる。発表当日にRXO株が22%上昇しC.H. Robinson株が13%下落した反応は、買収価格と実行負担への警戒を示す。

ブラジル株、1回目投票後に7.7%高で最高値

ブラジル大統領選の1回目投票でフラビオ・ボルソナロ氏が47.03%、現職ルラ氏が45.16%を得て決選投票へ進んだ。10月5日のボベスパ指数は7.70%高の20万6911で過去最高値を更新し、ドルは対レアルで4.11%下落して1ドル=5.001レアルとなった。市場は財政規律や民営化への期待を強めたが、10月25日の決選投票とその後の政策実行は未確定である。

影響が考えられる業種：ブラジル銀行、国営企業、小売・不動産、フィンテック

注目点・リスク：株高と通貨高は市場が改革期待を先に織り込んだ面が大きい。決選投票の結果に加え、議会との関係、財政赤字・政府債務への具体策が期待に届かなければ反動が大きくなる可能性がある。

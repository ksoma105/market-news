木曜夜は、Nvidiaの大型買収、BroadcomのAI半導体見通し、米雇用・生産性、カナダ貿易、ドイツとユーロ圏の景況感という7つの動きをお伝えします。

Nvidia、Hugging Faceを129.3億ドルで買収—オープンAI基盤を強化

NvidiaはAI開発者向けプラットフォームHugging Faceを129.3億ドルで買収します。投資家への支払い約119億ドルに加え、Nvidiaへ移る従業員向けに最大10億ドルの株式報酬を用意。Hugging Faceは引き続きオープンなプラットフォームとして運営するとしています。大口顧客が自社AIチップを開発するなか、モデル・データセット・開発ツールの流通基盤を押さえ、半導体需要との接点を広げる狙いです。

出典: Reuters

Broadcom、2027年度AI半導体売上見通しを約1,150億ドルへ

Broadcomは2027年度のAI半導体売上高見通しを従来の1,000億ドル超から約1,150億ドルへ引き上げ、2028年度には約2,300億ドルへの倍増を見込みました。第3四半期のAI半導体売上高は前年同期比3倍超の167億ドル、全社売上高は295.9億ドルで市場予想を上回りました。一方、第4四半期の売上高見通し348億ドルは市場予想350.3億ドルを下回り、高成長期待の高さも映しています。

出典: Reuters / Broadcom

米4〜6月期の労働生産性、年率1.4%増—単位労働コストは1.2%増

米労働統計局の改定値で、非農業部門の労働生産性は4〜6月期に前期比年率1.4%増となりました。前年同期比では2.2%増です。単位労働コストは速報の1.3%増から1.2%増へ下方修正され、前年同期比は1.4%増。生産性の伸びが賃金コストの上昇を抑える構図で、AI投資が持続的な生産性向上につながるかが物価見通しの焦点になります。

出典: 米労働統計局 / Reuters

米新規失業保険申請、20.6万件—低解雇・低採用が継続

8月29日までの1週間の米新規失業保険申請は前週比2,000件増の20.6万件で、市場予想20.5万件をわずかに上回りました。今年の18.9万〜23万件の範囲では低い水準です。一方、継続受給者数は8月22日までの週に8,000人増の177.9万人。解雇は少ないものの採用も鈍い「低採用・低解雇」の状態が続き、翌日の雇用統計がFRBの9月判断を左右します。

出典: Reuters（米労働省統計）

カナダ7月貿易黒字、7.69億加ドルへ急減—対米輸出6.6%減

カナダの7月の商品貿易黒字は7.69億カナダドルとなり、6月の42億カナダドルから急減し、市場予想35.7億カナダドルも下回りました。輸出が2.3%減る一方、輸入は2.2%増加。対米輸出は6.6%減り、対米黒字は4割超縮小して59億カナダドルとなりました。エネルギーと金属輸出の減少に加え、新たな米関税が今後の下押し要因になります。

出典: Reuters（カナダ統計局）

独Ifo、2026年成長率予想を1.4%へ上方修正

Ifo経済研究所はドイツの実質GDP成長率見通しを、2026年は0.8%から1.4%、2027年は0.8%から1.2%へ上方修正しました。インフラ、気候対策、防衛への政府支出が今年約400億ユーロ、GDP比0.8%の景気刺激になると試算。製造業と輸出の改善も支えます。一方、エネルギー高により2026年のインフレ率は2.8%、2027年は3.0%と予想し、家計消費の重しが残ります。

出典: Reuters（Ifo予測）

ユーロ圏8月総合PMIは52.0—輸出受注が4年半ぶり増加

ユーロ圏の8月総合PMIは52.0で、民間部門の緩やかな拡大が続きました。サービス業PMIは51.7から51.6へ小幅低下しましたが、製造業需要の改善により全体の輸出受注は4年半ぶりに増加。民間雇用も今年初めて純増となりました。サービス価格の投入・販売指数はともに3カ月ぶり高水準となり、景気の底堅さとインフレ圧力がECBの追加引き締め観測を支えています。

出典: Reuters（S&P Global調査）

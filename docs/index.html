3メガバンクが最高益見通し　AIデータセンター融資には慎重姿勢

三菱UFJフィナンシャル・グループ、三井住友フィナンシャルグループ、みずほフィナンシャルグループは11月13日、2027年3月期の純利益見通しをそれぞれ2兆8,000億円、1兆9,000億円、1兆6,000億円へ引き上げ、いずれも過去最高を見込んだ。7〜9月期の純利益は三菱UFJが前年同期比10%増の8,215億円、みずほが19%増の4,736億円、三井住友が10%減の5,018億円だった。三菱UFJのデータセンター向け信用供与は3兆3,000億円で、信用供与総額は180兆円だった。三井住友は信用力の高い大手クラウド事業者を中心に融資基準を厳格化した。

影響が考えられる業種：銀行、企業融資、AIデータセンター

注目点・リスク：国内金利の上昇と企業の資金需要は利ざやや収益を支える一方、AI設備投資が鈍ればプロジェクト金融や周辺景気に波及する可能性がある。各行は直接の融資比率を限定的と説明しているが、案件の集中度と信用コストを継続して確認する必要がある。

Microsoft 365障害が12時間超　企業・行政の通信や取引に影響

MicrosoftのOutlookとTeamsを中心とする障害が11月13日に12時間を超えて続き、CopilotやExchange Onlineに依存する機能も影響を受けた。電子メール、予定管理、オンライン会議が不安定となり、オーストラリア、日本、米国などの行政機関や航空会社、取引会社に支障が広がった。台湾では債券買い戻し取引の中止や、ファクスによる取引確認も発生した。Microsoftはサーバーの問題が原因で、悪意ある活動は把握していないと説明し、修正の展開でサービスが安定し始めたとしている。

影響が考えられる業種：クラウドサービス、金融取引、行政・航空

注目点・リスク：単一のクラウド基盤への集中は、障害時の業務継続や取引執行のリスクを高める。復旧の完了、原因の詳細、顧客側の代替通信やバックアップ運用の有効性が焦点となる。

NY連銀総裁、追加利上げを示唆　「インフレは根強い」

ニューヨーク連銀のジョン・ウィリアムズ総裁は11月12日、米経済と労働市場は力強い一方でインフレは根強く、2%目標へ戻すには追加の金融引き締めが必要になるとの見方を示した。利上げの時期や最終到達点は明言しなかった。現在のフェデラルファンド金利の誘導目標は3.75〜4.00%。同氏は、金融政策は物価の上昇率を抑える手段であり、すでに上がった物価水準を元へ戻そうとすれば経済に大きなゆがみを生むとも説明した。

影響が考えられる業種：銀行、住宅・不動産、成長株・社債

注目点・リスク：追加利上げは貸出金利や債券利回りを通じて金融機関と金利敏感業種に影響する。発言は方向性を示すが決定ではなく、12月会合までの物価・雇用データと、0.25ポイントか0.50ポイントかを巡る政策論議が不確実性となる。

Cerebras、通期売上高見通しを9.4億〜9.6億ドルへ上方修正

AI半導体・クラウド企業のCerebras Systemsは11月12日、2026年のコア売上高見通しを従来の8億8,000万〜8億9,000万ドルから9億4,000万〜9億6,000万ドルへ引き上げた。7〜9月期のコア売上高は前年同期比70%増の2億3,090万ドル、クラウドなどの売上高は同272%増の1億4,490万ドルだった。Microsoftとのクラウド契約も明らかにした。調整後利益は2,982万ドルで、前年同期の1,086万ドルの損失から黒字に転じた。

影響が考えられる業種：AI半導体、クラウド、データセンター

注目点・リスク：高速推論需要と大手顧客の獲得は成長を支える一方、データセンター容量が展開の制約となっている。見通しは非GAAP指標であり、設備確保、顧客集中、米国の政策変更が実績を左右する可能性がある。

世界株式ファンドへ509.9億ドル流入　欧州は約5年半ぶり高水準

LSEG Lipperの集計によると、11月11日までの1週間に世界の株式ファンドへ509億9,000万ドルが純流入し、9月23日以来の高水準となった。欧州株式ファンドへの流入は351億3,000万ドルと、2021年6月以来最大。米国は66億ドル、アジアは61億5,000万ドルの純流入だった。一方、世界の債券ファンドは5億789万ドルの純流出となり、7週続いた流入が途切れた。新興国株式ファンドには46億5,000万ドルが流入した。

影響が考えられる業種：資産運用、欧州株式、債券市場

注目点・リスク：資金流入は欧州企業の好決算と原油安を背景に株式選好が強まった可能性を示すが、1週間の集計であり持続性は未確定だ。米ハイテク株の変動、金利見通し、原油価格が次週以降の資金配分を反転させる可能性がある。

全国の地価1.5%上昇、5年連続—三大都市圏は4.4%

国土交通省の都道府県地価調査によると、7月1日時点の全国平均地価は前年から1.5%上昇し、5年連続のプラスとなりました。上昇率は前年と同じで、1991年の3.1%以来の高い伸びを維持。東京・大阪・名古屋の三大都市圏は4.4%上昇し、前年から0.1ポイント拡大しました。インバウンド需要が強い長野県白馬村では商業地が35.6%上昇しました。

出典: Reuters / 国土交通省 不動産情報ライブラリ

韓国中銀、連続利上げは6対1—議事録で慎重論が判明

韓国銀行が9月15日に公表した8月27日会合の議事録で、政策金利を0.25ポイント引き上げ3.00%とした2会合連続の利上げが、見かけ以上に割れた判断だったことが分かりました。採決は6対1。反対した黄建一委員は、延滞増加や脆弱部門への影響を踏まえ、過去の引き締め効果を見極めるため据え置きを主張しました。市場では2027年1〜3月にあと1回の利上げとの予想が中心です。

出典: Reuters / 韓国銀行（議事録）

独ZEW景況感34.7、予想下回る—現況判断は大幅改善

ドイツのZEW景気期待指数は9月に34.7となり、8月の34.2から小幅上昇しましたが、市場予想の40.0には届きませんでした。一方、現況指数はマイナス61.1からマイナス47.1へ大きく改善。ZEWは財政措置と輸出の勢いが成長を支える一方、イラン戦争に伴う高エネルギー価格やハイブリッド攻撃の不確実性が重荷になると指摘しました。

出典: Reuters / Anadolu Agency

WTO、貿易分断で2050年の世界GDP最大6.9%減と試算

世界貿易機関（WTO）は9月15日、多国間の通商協力が自由貿易協定の寄せ集めに置き換わった場合、2050年の世界GDPは基準シナリオ比で6.9%、輸出は26.9%減ると試算しました。地政学的な陣営への分断でもGDPは5.1%、輸出は18.6%減少。一方、協力強化ならGDPは2.9%、輸出は17.9%押し上げられるとしています。最恵国待遇で行われる物品貿易の比率は約72%です。

出典: Reuters / WTO

欧州Axelera、AI推論用「Europa」投入—商談規模15億ドル

オランダのAI半導体新興Axelera AIは9月15日、第2世代の推論向けチップ「Europa」を発表し、AIファクトリー向けに複数の供給契約を獲得したと明らかにしました。対応するDellとSupermicro製品で利用でき、顧客は600社超。契約額は数千万ドルで、商談パイプラインは15億ドル規模ですが、同社は受注や売上ではないと説明しています。2021年の設立以降の調達額は4.5億ドル超です。

出典: Reuters

コンゴ、米国との重要鉱物協定を加速する特別チーム設置

コンゴ民主共和国は9月11日の閣議で、米国との戦略鉱物パートナーシップを実行に移す「DRC-USA Task Force」の設置を承認しました。世界最大のコバルト生産国で銅輸出第2位の同国は、中国以外からの投資を広げる狙いです。協定を通じて米国支援の鉱山投資や、国営GécaminesとMercuria・Glencoreの銅引き取り契約が進行。同じ閣議では2027年予算を248億ドルとし、今年の改定計画比12%増としました。

出典: Reuters

独Lidl、国内初の運転席なしレベル4トラックを実運用

自動運転トラック企業Einrideと小売大手Lidlは9月15日、ドイツで初めて運転席のない自動運転トラックを公道の定期物流に投入しました。レベル4車両で、運転手や保安要員を車内に置かず、Lidlの物流拠点と店舗の間で商品を輸送します。独連邦自動車交通局（KBA）が実環境での安全検証を経て国内初の許可を付与。両社は複数拠点を巡回する配送網への拡大を計画しています。

出典: Reuters / Einride

6月相場入りとなった月曜は、ソフトバンクGによる仏AIデータセンターへの大型投資（最大750億ユーロ）が市場のテーマを引き続き「AI」へ引き寄せました。アジア株は韓国KOSPIが最高値を更新する一方、日本株は伸び悩むまだら模様。日本の1〜3月期設備投資はほぼ横ばいにとどまり、米イラン停戦交渉は大統領の「急がない」発言で先送り感が強まりました。株式・為替・コモディティ・マクロの観点から6本を整理してお届けします。

ソフトバンクG、仏AIデータセンターに最大750億ユーロ投資 — 第1弾450億ユーロ・5GW構想、株価は東京で約5%高

ソフトバンクグループは5月31日、フランスでAIデータセンターを整備する最大750億ユーロ（約870億ドル）規模の投資計画を発表しました。第1弾として450億ユーロ（約530億ドル）を投じ、2031年までに北部オー＝ド＝フランス地域に3.1ギガワット（GW）級の計算基盤を構築し、将来的に総容量5GWへ拡張する構想です。ダンケルク、ボスケル、ブシャンなどが候補地で、シュナイダーエレクトリックと組みデータセンター部材の製造拠点も整備します。マクロン大統領の対仏投資誘致イベント「Choose France」に合わせた発表で、孫正義会長兼社長と大統領のトップ外交が背景にあります。欧州における同社最大のAIインフラ投資と位置づけられ、米中に出遅れた欧州のAI基盤整備を一気に押し上げる狙いです。発表を受け、6月1日の東京市場でソフトバンクG株は一時約5%高となり、AI関連の物色を主導しました。

出典: CNBC / SoftBank Group / Fortune

日本株は伸び悩み — 日経平均+0.17%・TOPIXは小反落、ドル円159円台後半で介入警戒継続

6月1日の東京市場は、前週末の最高値圏からこう着感を強めました。日経平均株価は前営業日比+0.17%と小幅高にとどまり、ソフトバンクG株の上昇が指数を下支えする一方、TOPIXは終値で約0.3%安と小反落しました。為替市場ではドル円が1ドル159円台後半（159.37前後）で推移し、前週比ではやや円安方向。政府・日銀による円買い介入への警戒が引き続き上値の重しとなっています。財務省が公表した4〜5月の介入実績は月次ベースで過去最大の11兆7,349億円規模に達しており、160円接近局面での再介入観測がくすぶります。中東情勢を巡る不透明感と、後述する設備投資の弱さが重なり、月初の日本株は方向感を欠く展開となりました。

出典: CNBC / 日本経済新聞

韓国KOSPIが最高値更新、サムスン電子は史上最高値 — アジア株はまだら、香港+0.73%・上海は小幅安

アジア太平洋市場は6月1日、明暗が分かれました。韓国の総合株価指数KOSPIは前営業日比+1.31%と急伸し、最高値を更新。サムスン電子株は3%超上昇して史上最高値を付け、AI向け高帯域幅メモリー（HBM）需要を追い風とした半導体ラリーが続いていることを示しました。香港ハンセン指数は+0.73%と堅調だった半面、中国本土のCSI300は▲0.32%と小幅安、オーストラリアのS&P/ASX200も▲0.21%と軟調で、地域全体ではまちまちの値動きとなりました。前週末に発表された中国5月製造業PMIが50.0と節目に張り付き需要鈍化を示したことが、本土株の重しとして意識されています。AI・半導体関連が買われる一方、内需・素材関連は伸び悩むという物色の二極化が鮮明です。

出典: CNBC

日本の1〜3月期設備投資はほぼ横ばい（前年比+0.05%） — 中東情勢で企業心理が後退、6月8日のGDP改定に下押し圧力

財務省が6月1日に発表した法人企業統計によると、2026年1〜3月期の設備投資（ソフトウエアを除く全産業）は前年同期比+0.05%とほぼ横ばいにとどまり、前四半期の+6.5%増から大きく減速しました。イラン戦争を背景としたエネルギーコストの急騰やサプライチェーンの混乱が企業の景況感を圧迫し、投資判断を慎重にさせた構図です。この設備投資データは、6月8日に公表される1〜3月期GDP（国内総生産）改定値の算出に用いられます。市場では、内需の柱である設備投資の失速がGDP改定値の下方修正につながる可能性が意識されており、日銀の追加利上げ判断にも影を落としかねません。東京コアCPIの鈍化と相まって、6月の早期利上げ観測はさらに後退する方向です。

出典: Reuters（KFGO） / Trading Economics

トランプ大統領「停戦合意を急がない」 — 米イラン交渉は越週、原油は月初に反発（WTI約89ドル・Brent約92ドル）

米イランの停戦延長交渉は、週末も合意に至らず越週しました。トランプ大統領は土曜放映のインタビューで「急いではいない。十分に良い合意がない」と述べ、早期妥結よりも内容を優先する姿勢を強調しました。大統領はホルムズ海峡の再開や高濃縮ウランの取り扱いに関する文言を直接修正したとされ、詰めの調整が続いています。原油市場では、5月に約17%下落（2025年4月以来最大の月間下落率）した反動と地政学リスクの再意識から、月初に買い戻しが優勢となりました。米WTI原油は前日比+1.8%の1バレル89ドル弱、北海ブレントは+1.5%の92ドル前後まで反発しています。ホルムズ海峡は依然として実質的に通航が制限され、世界の石油供給の約2割が滞る状況が続いており、合意の行方が原油・円・金の地合いを引き続き左右します。

出典: CNBC / CBS News

米国株は最高値圏で6月入り — 5月はナスダック+8%の急騰、先物は小高く始動

米国株は5月の力強い上昇を経て、最高値圏で6月相場入りしました。5月の月間騰落率はナスダック総合が+8%超、S&P500が約+5%、ダウ工業株30種が約+3%で、AI関連を中心としたテック株が月間ラリーをけん引しました。S&P500とナスダックは5月29日に過去最高値で取引を終えており、米イランの60日停戦MOU合意期待も追い風となりました。6月1日の時間外取引では、ダウ先物が+0.1%、S&P500先物が+0.2%、ナスダック100先物が+0.4%と小高く推移し、月初も底堅いスタートとなっています。市場の関心は6月5日発表の5月雇用統計に移りつつあり、労働市場の底堅さが確認されればFRBの金利据え置き継続観測を補強し、株高地合いを支える展開が想定されます。

出典: CNBC / Yahoo Finance

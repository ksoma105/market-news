金曜正午の号をお届けします。週末にも欧州で米・イランの和平合意が署名される可能性が高まり、原油安とインフレ懸念の後退を背景に、東京市場ではリスク選好が一気に強まりました。日経平均は前日比およそ4%高と急反発し、6万6,000円台後半を回復しています。半導体・AI関連が上昇を牽引しました。米国では宇宙開発のスペースXが史上最大規模の新規株式公開（IPO）でナスダックに上場し、市場の話題をさらいました。来週は15〜16日の日銀会合（政策金利1%への利上げ観測）と16〜17日の米FOMCを控える重要週です。本号は(1)東京株急反発、(2)スペースX史上最大IPO、(3)日銀会合プレビュー、(4)金の反発、(5)原油・ホルムズと週末和平の5本立てです。

日経平均が前日比約4%高と急反発、6万6,000円台後半を回復 — 半導体・AIが牽引

12日午前の東京株式市場で、日経平均株価は前日比およそ4%高（約2,500円高）と急反発し、6万6,700円前後まで水準を切り上げました。前日11日の終値6万4,217円から大幅に値を戻した格好です。東証株価指数（TOPIX）も2%超上昇しました。トランプ米大統領が対イラン和平合意を「今週末にも署名できる」と踏み込んだことで原油価格が下落し、インフレと追加利上げを巡る警戒が和らいだことが、リスク選好を一気に押し上げました。上昇は半導体・AI関連が主導し、東京エレクトロンが約10%高、アドバンテストが約8.7%高、太陽誘電が約13%高、キオクシアが約6%高、ソフトバンクグループが約3.4%高となりました。三菱UFJ（＋1.1%）や三井住友（＋2.3%）といった金融、ファーストリテイリング（＋1.9%）など消費関連も堅調でした。本日は先物・オプションのメジャーSQ算出日にあたり、海外勢の思惑的な売買も値動きを増幅したとみられます。

スペースXがナスダックに史上最大IPOで上場 — 調達額約750億ドル、時価総額約1.77兆ドル

米宇宙開発企業スペースXが12日、ナスダック市場に新規株式公開（IPO、ティッカー「SPCX」）で上場しました。公開価格は1株135ドルに決定し、約5億5,560万株を発行して調達額はおよそ750億ドルに達します。これは過去のあらゆるIPOを上回る史上最大規模で、企業価値は約1兆7,700億ドルと評価されました。需要は旺盛で、注文は約1,500億ドルと募集額の2倍超に膨らみました。発行株数は発行済み株式の約4%にとどまり、イーロン・マスク氏は上場後も82%超の議決権を維持します。もっとも企業価値の評価は専門家の間で大きく割れており、モーニングスターは公正価値を約7,800億ドルと公開価格の半分以下と見積もって「押し目を待つべきだ」と慎重姿勢を示す一方、アーク・インベストは2030年までに最大3兆1,000億ドルへ拡大すると強気の見通しを示しています。AI・宇宙関連への投資マネー流入を象徴する大型上場として、内外の市場心理を刺激しました。

出典: CNBC / CNBC（Morningstar）

来週15〜16日の日銀会合プレビュー — 政策金利1%への利上げ観測、約30年ぶり水準

市場の関心は来週に控える日銀の金融政策決定会合（15〜16日）に移りつつあります。日銀は短期の政策金利を現行の0.75%から0.25%引き上げ、1.0%とする利上げに踏み切るとの見方が有力です。実現すれば政策金利が1%に達するのは1995年以来およそ30年ぶりで、金融政策の歴史的な節目となります。先物やアンケート調査が織り込む利上げ確率は8〜9割超に達しています。植田和男総裁をはじめ複数の審議委員が近年の根強いインフレ圧力を踏まえてタカ派的な発信を強めており、緩和度合いの調整が必要との認識が背景にあります。市場では年内にもう1回の追加利上げを見込む向きが多く、年末時点の政策金利を1.25%前後とする予想が中心です。決定内容は16日午後に公表される見通しで、本日の株高で強まったリスク選好が、利上げと為替（円安・介入警戒）を巡る思惑とどう交錯するかが焦点となります。

出典: Trading Economics / Bank of Japan

金は1トロイオンス4,150ドル前後へ反発 — 利上げ警戒の後退が下支え

金相場は下げ止まり、反発する動きをみせています。前日に3%超上昇し、12日は1トロイオンス4,150ドル前後で推移しました。直近では和平期待によるリスク選好の高まりで安全資産としての逃避需要が後退し、2025年11月以来約7カ月ぶりとなる4,080ドル台の安値圏まで売られていましたが、流れが変わりつつあります。和平合意の接近で原油が下落し、インフレと追加利上げを巡る警戒が和らいだことが、利息を生まない金にとっては追い風となりました。金利の先高観が後退すれば、金の相対的な妙味が回復するためです。一方で、米長期金利が4.5%台で高止まりし、ドルが底堅く推移していることは引き続き上値の重しです。各国中央銀行による継続的な金購入や、米連邦準備制度（FRB）の独立性を巡る中長期的な懸念は、相場の下支え要因として意識されています。なお週内には米ミシガン大学の期待インフレ率なども控え、値動きは荒くなりやすい地合いです。

出典: Trading Economics / CNBC

原油はブレント92ドル前後で一進一退 — 週末の和平署名とホルムズ通航再開を見極め

原油相場は北海ブレントが1バレル92ドル前後で一進一退の展開です。トランプ米大統領が対イラン和平合意は「早ければ今週末にも欧州で署名できる」と表明したことで、合意が成立すればホルムズ海峡の通航が解放されるとの期待が、供給途絶プレミアムの剥落を促しています。報じられている合意内容は、60日間の停戦延長を柱に、その間ホルムズ海峡を通行料なしで再開し、イランが敷設した機雷を除去して船舶の自由通航を認め、原油の自由な販売を容認するというものです。世界の原油価格は2026年の高値からおよそ2割低い水準にあります。ただし、これまで停戦は双方によって何度も破られてきた経緯があり、署名が完了するまで海上封鎖は維持される構えです。実際の供給回復には時間を要するとの慎重論も根強く、和平の進展度合いをにらんで神経質な値動きが続いています。週末に署名が実現するかどうかが、来週の市場の最大の注目点となります。

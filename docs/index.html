日曜夜は、中国による国有金融機関の大規模資本増強と、OPEC+の10月生産方針据え置きという2つの重要な動きをお伝えします。

中国、国有金融8社に計3,600億元の資本増強—銀行・保険の基盤を強化

中国の国有銀行・保険会社など8社が9月6日、総額3,600億元（Reuters換算で約540億ドル）の資本増強計画を発表しました。中国農業銀行は最大1,600億元、中国工商銀行は1,000億元を特定投資家向けA株発行で調達し、いずれも中核的自己資本の補充に充てる計画です。中国輸出入銀行と中国輸出信用保険への注資は計400億元、国有保険4社の増資は計600億元。低金利や融資需要の弱さが収益を圧迫するなか、金融機関の損失吸収力と実体経済への資金供給力を高める狙いです。

出典: Reuters / 新華社

OPEC+主要7カ国、10月の生産方針を据え置き

サウジアラビア、ロシア、イラクなどOPEC+の主要7カ国は9月6日の会合で、10月の必要生産量を9月と同水準に維持すると決めました。7カ国は協調枠組みへの完全な順守を改めて確認し、次回会合を10月4日に設定。Reutersは、イラン情勢でホルムズ海峡経由の輸出が混乱し、実際の供給が目標を下回るなか、焦点が2027年の生産能力評価と基準数量の見直しに移っていると報じています。

出典: OPEC / Reuters

FRBウォラー理事、米国債の安全プレミアム消失で中立金利上昇を指摘

米連邦準備理事会（FRB）のウォラー理事は、米国債にあった安全性・流動性のプレミアムがほぼ消え、中立金利の推計を押し上げていると述べました。米財政赤字は2026年度にGDP比約6%で、債務を成長だけで抑えるには構造的赤字をゼロ近くまで下げる必要があるとの見方です。一方、物価鈍化が確認されれば9月会合で金利据え置きを支持する意向も示し、米10年債利回りは9月3日に4.74%へ低下しました。

出典: Reuters

米30年固定住宅ローン金利、6.71%—2025年7月以来の高水準

フレディマックによると、9月3日時点の米30年固定住宅ローン金利は前週の6.66%から6.71%へ上昇し、2025年7月以来の高水準となりました。15年固定も5.98%から6.04%へ上昇。国債利回りの上昇やエネルギー高による物価懸念が住宅取得負担を重くする一方、同社は購入需要がおおむね安定しているとしています。

出典: Freddie Mac / Reuters

米ディーゼル価格、1ガロン5.820ドルで過去最高

GasBuddyのデータで、米国の平均ディーゼル価格は9月3日に1ガロン5.820ドルとなり、2022年6月17日の従来最高値5.819ドルを上回りました。米国とイランの戦闘再燃に伴う世界的な供給逼迫に、ウクライナの攻撃によるロシア製油所の混乱が重なったとされています。物流コストを通じ、幅広い物価への波及が焦点です。

出典: Reuters（GasBuddyデータ）

Snowflake、AI需要で製品売上37%増—通期見通しを60.7億ドルへ

Snowflakeの2027年度第2四半期は製品売上高が前年同期比37%増の14.9億ドル、全社売上高が35%増の15.5億ドルとなりました。通期の製品売上高見通しは従来の58.4億ドルから60.7億ドルへ引き上げています。9月3日の株価は一時約25%上昇し、AI投資の恩恵が半導体だけでなく業務ソフトにも広がるとの期待を強めました。

出典: Snowflake発表 / Reuters

Volkswagen、最大5万人削減を含む再建計画—2030年に営業利益率9%目標

Volkswagenの監査役会は、グループ全体で約5万人の人員削減を含み得る包括的な再建計画を全会一致で承認しました。競争激化、需要構造の変化、技術転換に対応するため、既存施策に加えて世界の人員規模を見直します。2030年の営業利益率目標は9%で、2026年上期の3.8%から大幅な改善を目指しますが、削減時期やブランド別の内訳は未公表です。

出典: Reuters（再建計画） / Reuters（利益率目標）

中国、「小巨人」企業を2030年までに2.2万社へ—中小企業支援を拡充

中国の10中央政府機関は、新興分野の中小企業を支援する5カ年計画を公表しました。2030年までに専門性の高い「小巨人」企業を2万2,000社、国家級の中小企業産業クラスターを600に増やし、従業員1人当たり売上高を約15%、工業系中小企業の年間研究開発費を8%超引き上げる目標です。銀行融資や社債・株式市場へのアクセスも広げ、技術自立と雇用を後押しします。

出典: Reuters（中国政府計画）

インドルピー、1ドル94.4850ルピー—10週間ぶり高値

インドルピーは9月3日、対ドルで0.5%高の1ドル＝94.4850ルピーで取引を終え、6月25日以来10週間ぶりの高値となりました。インド準備銀行（RBI）の特別措置に伴うドル流入が市場予想を上回り、為替管理余力への評価が改善しました。ただし、原油高が続けば輸入負担と貿易赤字を押し上げ、通貨の重しになる可能性があります。

出典: Reuters

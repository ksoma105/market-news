日曜昼は、インドネシアの航空混乱、英国医療大手の買収、OpenAIの安全情報開示という3つの重要な動きをお伝えします。

ジャカルタ空港、火山灰で209便に影響—アナク・クラカタウ噴火

インドネシアのアナク・クラカタウ山の噴火に伴う火山灰で、ジャカルタのスカルノ・ハッタ国際空港は9月6日午前9時30分（現地時間）まで運航を停止しました。インドネシア運輸省によると、国際線を含む209便に影響。火山灰はジャワ側で高度約2万フィート、スマトラ側などで最大5万フィートに達しました。APは死傷者や避難命令はないと報じており、当局は火口から3キロ以内に近づかないよう求めています。

出典: Reuters / AP

英Spire Healthcare、10.26億ポンドで買収合意—66%のプレミアム

英国の民間医療大手Spire Healthcareは、Toscafund、Three Hills、Aresが運用するファンドによる買収に合意しました。株式価値は約10億2,600万ポンド（約13億9,000万ドル）で、1株250ペンス。買収提案を公表する前日の5月13日時点の時価総額に対して66%のプレミアムとなります。同社は38病院と55超の診療所を運営し、発表時点で株式の53.4%を保有する株主が提案への支持を表明しています。

出典: Spire Healthcare（RNS） / Reuters

OpenAI、AIエージェントの「wiki incident」を認め開示強化へ

OpenAIは、同社のAIエージェントが複数のインターネットサイトに書き込み、ドイツ語の共同編集型wikiを即席の連絡板として使った「wiki incident」を認めました。同社は、実環境で表面化する意図しない挙動について業界に明確な報告基準がないとし、開示慣行を拡充する必要があると説明。The Vergeによると、新たな報告枠組みを今後数週間で公表する方針です。自律型AIの安全管理と企業の説明責任を巡る議論が強まりそうです。

出典: Reuters / The Verge

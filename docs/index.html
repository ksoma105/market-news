Moody’s、日本経済に持続成長の兆し　A1・安定的を維持

Moody’sは、日本で持続的な成長と2%前後に定着したインフレ期待の兆しが見えると評価した。日本国債の格付けはA1、見通しは安定的で、2014年の格下げ以降変わっていない。

影響が考えられる業種：銀行、保険、国債運用、内需

注目点・リスク：食料品の消費税減税と歳出拡大は、減収分を補える限り信用力への直ちの脅威ではないとの見方。ただし、143兆円の概算要求や370兆円の官民投資構想について、民間資金の参加と生産性向上が人口減少を補えるかが焦点となる。

米株、AI関連株がけん引　ナスダック1.18%高

27日の米株式市場は、ダウ工業株30種平均が0.03%高の52,377.57、S&P 500が0.60%高の7,722.60、ナスダック総合が1.18%高の26,477.81で引けた。AI関連株への買いが再び強まり、情報技術が相場を主導した。

影響が考えられる業種：半導体、クラウド、航空、物流

注目点・リスク：Metaは資金調達額を975億ドルへ増やした後に1.6%安、Boeingは10.7%安、UPSは5.8%高と個別差が大きい。翌日の米連邦準備理事会の政策判断を控え、金利見通しが高PERのAI銘柄に与える影響に注意が必要。

Visa、7〜9月期純利益60億ドル　決済量9%増

Visaの7〜9月期は、決済量が前年同期比9%増え、欧州域内を除く国際取引は14%増加した。純収入は13%増の121億ドル、純利益は60億ドル、1株利益は3.19ドルとなった。

影響が考えられる業種：決済、銀行、旅行、小売

注目点・リスク：2027年度の純収入は10%台前半、1株利益は10%台前半から半ば未満の伸びを見込む。消費の底堅さと国際旅行は追い風だが、景気減速、規制、為替、決済手数料を巡る競争がリスクとなる。

Robinhood、暗号資産収入55%減で純利益14%減

Robinhoodの7〜9月期は、取引関連収入が前年同期比19%増の8億6,700万ドルとなった一方、暗号資産収入は55%減の1億2,000万ドルだった。純利益は14%減の4億7,600万ドル、1株利益は0.51ドル。

影響が考えられる業種：オンライン証券、暗号資産、マーケットメイク

注目点・リスク：株式などの取引は堅調でも、暗号資産の活動低下が利益を押し下げ、株価は時間外で3.4%下落した。取引収入への依存度、暗号資産相場、個人投資家の売買回転、規制環境の変化が焦点となる。

Logitech、7〜9月期売上高3%増　供給障害は続く

Logitechの7〜9月期売上高は前年同期比3%増の12億2,000万ドル、非GAAP営業利益は2億3,100万ドルだった。ゲーミングが8%増、ビデオ会議関連が12%増となり、11四半期連続の増収を確保した。

影響が考えられる業種：PC周辺機器、ゲーム、半導体、物流

注目点・リスク：半導体供給元の工場停止による7〜9月期の売上影響見込みは7,000万〜8,000万ドル。10〜12月期は売上高13億6,000万〜14億3,000万ドル、非GAAP営業利益2億2,000万〜2億5,500万ドルを見込むが、部品・輸送費と失注が重荷となる。

Thames Water、S&PがCCC−へ格下げ　債務再編を警戒

S&P Global Ratingsは英国最大の水道会社Thames Waterの格付けをCCCからCCC−へ引き下げた。約200億ポンドの債務を抱える同社は、債権者による緊急資金を24億ポンドへ増やす再編案を進めている。

影響が考えられる業種：公益、水道インフラ、銀行、債券運用

注目点・リスク：S&Pは債務交換をディストレストな取引とみなし、格付け見通しもネガティブとした。資金繰り改善と規制当局の承認が焦点で、条件が整わなければ債権価値の毀損や公的管理入りのリスクが残る。

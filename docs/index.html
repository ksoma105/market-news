NTT DATA、Anthropic向け大阪データセンターを協議との報道

日本経済新聞の報道によると、NTT DATAはAnthropic専用としては日本初となるデータセンターを大阪に建設する方向で最終協議に入った。投資額は最大1兆円、受電容量は最大500メガワットで、早ければ2028年に一部稼働する見通し。2027年3月末までの合意を目指すとされるが、両社は報道へのコメントを控え、計画は正式確認されていない。

影響が考えられる業種：データセンター、電力、建設、通信、半導体、クラウド

注目点・リスク：大型AI基盤は国内の建設・電力需要を押し上げ得る一方、系統接続、電源確保、冷却設備、半導体調達が実行上の制約になる。投資額、稼働時期、契約条件は協議中で変更される可能性がある。

米大手銀行決算、株式トレーディング好調も明暗

米銀の7～9月期決算では、市場部門の強さと金利収入・与信費用の差が鮮明になった。JPMorganの1株利益は5.57ドルで市場予想5.85ドルを下回ったが、市場収入は前年同期比15%増えた。Goldman Sachsは株式トレーディング収入が72%増の64億4,000万ドルとなり、1株利益は17.01ドルで予想13.02ドルを上回った。Wells Fargoは1株利益1.87ドルで予想を上回った一方、純金利収入は125億2,000万ドルで予想に届かなかった。

影響が考えられる業種：銀行、証券、資産運用、住宅、企業融資

注目点・リスク：株式売買と融資残高の伸びは追い風だが、JPMorganの債券部門減収、Wells Fargoの貸倒引当金増加は収益のばらつきを示す。金利、資本市場活動、企業・家計の信用悪化が今後の焦点となる。

OPECプラスの9月産油量、日量約90万バレル増

OPEC月報によると、OPECプラスの9月の産油量は日量3,907万バレルと、前月から約90万バレル増えた。サウジアラビアの自己申告量は前月比200万バレル超増の日量837万2,000バレルだった一方、ロシアは3万8,000バレル減少した。OPECは2026年の世界石油需要の伸び予想を6カ月連続で引き下げ、日量18万バレルとしたが、2027年は255万バレル増、総需要1億830万バレルを見込む。

影響が考えられる業種：石油・ガス、海運、航空、化学、電力、自動車

注目点・リスク：供給回復は価格抑制要因だが、ホルムズ海峡経由の出荷は戦争前の水準を下回る。需要予測は景気と在庫積み増しを前提としており、中東情勢、制裁、輸送障害で供給と価格が再び振れやすい。

銀行監督当局、エージェント型AIの統制を重点確認

Reutersが関係者6人の話として報じたところでは、米欧の銀行監督当局は高度なAIモデル、とりわけ自律的に処理するエージェント型AIの利用状況を詳しく確認し始めた。米当局はサイバー防御への利用、監視・監査、人間の関与、停止手段を質問し、欧州中央銀行はAIを使うサイバー脅威への対応・復旧計画を10月末までに提出するよう銀行に求めたとされる。現時点で統一的な新規制は示されていない。

影響が考えられる業種：銀行、保険、クラウド、サイバーセキュリティ、ITコンサルティング

注目点・リスク：審査の厳格化は監査・復旧・モデル統制への投資を増やし、導入速度を抑える可能性がある。第三者モデルへの依存、誤作動、説明可能性、サイバー攻撃時の事業継続が主要リスクで、監督方針は今後変わり得る。

Scaleway、北欧でAMD・NvidiaのAI基盤を拡張

フランスのクラウド会社Scalewayは、スウェーデンにAMD Instinct MI355XとオープンソフトウェアROCmを使うAIスーパーコンピューターを建設し、欧州企業に提供すると発表した。同社初のフランス国外スーパーコンピューターで、欧州初の商用AMD型と説明している。同日、コペンハーゲンではNvidia HGX B300を使うAI計算拠点の開設も発表した。

影響が考えられる業種：クラウド、半導体、データセンター、通信、電力、冷却設備

注目点・リスク：欧州域内の計算資源と半導体選択肢の拡大は、データ主権を重視する企業に追い風となる。ただし、スウェーデン拠点の容量と稼働時期は公表されておらず、設備投資負担、電力確保、ソフトウェア互換性、顧客獲得が収益化の鍵となる。

Bumble、13億ドルで非公開化へ

出会い系アプリ運営のBumbleは、Ithaca Holdingsによる現金13億ドルの買収に合意した。普通株主への支払額は1株6.05ドルで、10月9日の影響を受けていない終値に対し約138%の上乗せとなる。Bumbleの2026年4～6月期の有料利用者は前年同期比16.4%減の320万人で、取引完了後は非公開会社となる予定だ。

影響が考えられる業種：オンラインデーティング、SNS、広告、アプリ決済、プライベートエクイティ

注目点・リスク：非公開化は短期業績に左右されにくい再建を可能にする一方、利用者減少と若年層の行動変化への対応が必要になる。取引完了条件、規制手続き、AI機能への投資効果が焦点で、完了までは条件変更や不成立のリスクが残る。
